## 1. 这是什么

**一句话**：对湛江对虾 / 海水养殖场景的 AI 类大创选题做**系统性的可行性审查**，
并在通过审查的方向上完成**完整的项目交付**（调研 → 申报 → 技术 → 原型 → 验证 → 成果 → 结题 → 复盘）。

本工作区不产出"好点子"，产出的是**被证据支持的选题判定**，以及**能被追问的交付物**。

**为什么存在**：上一轮《蓝哨》项目以「文献缺口 / 没人做」作为立项依据被拒
（复盘见 `E:\BJTU\GDOU-CXCY\GDOU-CXCY-AI-Z2B-2\08-复盘\大创选题失败原因分析.md`）。
该复盘是本项目最重要的输入 —— 本工作区的**三门禁方法**、**五级检索半径**、
**表述红线**全部是从那次失败里反推出来的。

## 5. ⚠️ README 层级规则（**重要，先读**）

本工作区的 README 是**四层**的，每层职责不同。**冲突时以层级更低（更具体）的为准。**

| 层级 | 文件 | 职责 | 授权级别 |
|---|---|---|---|
| L0 | `README.md`（本文件） | 导航 + 纪律；**不下结论** | 不具权威性 |
| L1 | `project/README.md`、`doc/README.md`、`tools/README.md` | 目录用途说明 | 不具权威性 |
| L2 | `<项目>/README.md`（如 `project/F1/README.md`） | 项目对外入口 | 参考 |
| L3 | **`<项目>/00-项目管理/项目总览-README.md`** | ★ **唯一事实来源** | **最终权威** |

**关键纪律**：

- 本文件与 L1/L2 README **不复制**权威数字的完整清单，只做**指针**。
  理由：本工作区已有两次因"派生值被手抄"导致口径不一致的教训（F4 的 D-3 / D-4）。
- **派生统计值**（代码行数、实验通过数、文献篇数）要么**引用来源文件**，要么**由脚本注入**，
  **不得手抄**。
- 同一材料出现两个口径的数字时，**必须写明口径**（如 F4：原型系统本体 vs 含演示工具，两者都对）。

## 7. 表述红线（**违反即作废**）

1. **不编造**文献、DOI、作者、期刊、数字、产品名、备案号。
2. **「我没检索到」≠「不存在」** —— 禁止把检索范围当成事实边界。
   否定性表述一律写成「**在所及范围内未见**」+ **举证范围** + **举证日期**，
   并附「**未见披露 ≠ 不存在**」。
3. **立项走能力差异型论证**，**不得**用「文献空白 / 没人做 / 国内首创」立项。
   禁用词：均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 / 未检索到同类 / 国内首个 / 首创。
4. **中文期刊（CNKI / 万方）覆盖不足必须如实声明。**
5. **合成数据的效应量不得外推真实塘口。**
6. **任何对外报告的效应值必须携带**识别假设清单、样本量、方法名 —— 禁止只报一个孤立数字。
7. 门禁 B 问 2 的答案必须是「**动机不匹配**」或「**粒度不匹配**」，
   **不能是「他们没想到」**（偶然、随时可消除，撑不起项目）。

## 8. 已知边界与缺口（如实声明，不掩盖）

| 缺口 | 影响 | 涉及 |
|---|---|---|
| **未覆盖 CNKI / 万方**（中文期刊） | 所有「国内未见」类结论**强度降一级** | 全部方向 |
| **未覆盖专利库** | 第三轮最强占位者多条是**专利**，且常先于论文公开 | 门禁 A |
| **未覆盖学位论文库** | 国内硕博论文可能已做同类工作 | 门禁 A |
| **无真实塘口数据** | F1 / F4 的全部结论来自**合成数据或文献引用**；**不存在"实测准确率"** | F1、F4 |
| **OpenAlex 曾返回 429** | `tools/f1_fetch.py` 的 22 条补充检索式**一条也没跑** | F1 门禁 C |
| **F1 未实现 CATE / 异质性** | `synth.py` 不含 T×X 交互 ⇒ 无法检验异质性检测能力 | F1 |
| **文档 ↔ 代码一致性无自动检查** | `consistency_check.py` 只做**文档之间**校验 | 全部项目 |

> **方法论结论（本项目最可复用的产出）**：
> **判据设计错误与实现缺陷数量相当，且更危险 —— 因为它不报错，会产出"看起来正确"的错误结论。**
> 一个诊断若没经过「**零假设下应报什么**」的验证，它的阳性结果毫无意义。
