# 第三轮扩展 · 新方向筛选约束

> 依据：`project/16-方向审查/00-总览/16方向审查总报告.md` 的三个发现 + 三门禁方法论。
> 审查时点：2026-09-20。本文只写**筛选标准**，方向清单与证据见同目录其余文件。

## 一、硬性筛选标准（不合格者第一轮淘汰，不进入文献检索）

资源禀赋事实（前两轮已坐实）：**有算力、有方法、没有塘口、没有硬件预算、没有现场准入。**

因此，一个候选方向若要求下列任一项，直接淘汰：

| 判死条件 | 理由 |
|---|---|
| 需要进塘口 / 现场准入 | 无准入保证 |
| 需要自购硬件设备（>3000 元） | 预算 1 万元 |
| 需要企业 / 政府内部数据 | 无获取渠道 |
| 需要水产 / 生物 / 机械 / 水声专业背景 | 队伍全为软件工程 |
| 需要生成式 AI 服务备案 | 准入制，12 个月内无法完成 |
| 需要湿实验 / 生物样本 | 无实验条件 |

## 二、门禁 B 的额外要求（本轮收紧）

前两轮的教训：**「别人已经做了」是最主要的失败原因（6/16）**。本轮在正式审查前，
先把每条候选的**「最近占位者半径」**预判一遍，只保留满足下列条件者：

1. 门禁 B 问 2 的答案必须是 **动机不匹配** 或 **粒度不匹配**（不能是"他们没想到"）。
2. **不得**以「没人做」为立项依据——只允许做**能力差异型**或**方法缺口型**论证。

## 三、与前两轮 16 方向的去重纪律

已审查的 16 个方向：D1–D6（智能投喂 / 水下视觉 / 水质预警 / 病害诊断 / 边缘部署 / 大模型知识）、
E1–E10（物联网感知 / 数字孪生 / 数据质量 / 水下机器人 / 投喂装备 / 模型轻量化 /
溯源 / 无人机遥感 / 水下声学 / AI 可信性）。

**新方向必须与这 16 个在「研究对象 + 研究问题」两个维度上都不重叠。**
仅换一个应用场景（例如"把水质预警换成溶氧预警"）不算新方向。

## 四、本轮允许的新方向类型（三个来源）

| 来源 | 说明 |
|---|---|
| **T1 技术迁移型** | 把某个**在别的领域已成熟的方法**迁移到对虾/水产场景，且迁移本身有方法论缺口 |
| **T2 新数据源型** | 用**新的、公开的、不需要准入的数据源**（如遥感、公开基因组、公开图像库、气象数据） |
| **T3 横切工具型** | 面向**养殖 AI 开发生命周期**的软件工具（不产生养殖数据，只处理数据） |

## 五、表述红线（全文适用）

禁用：均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 / 未检索到同类 / 国内首个 / 首创。

替代：「在所及范围内未见」。所有否定性结论必须给**举证范围与日期**，
并附「未见披露 ≠ 不存在」声明。
