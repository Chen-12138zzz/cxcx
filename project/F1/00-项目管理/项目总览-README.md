## 2. 立项依据

### 2.1 一句话立论

> **本项目做「养殖观测数据上的干预效应估计流程与识别有效性审计」。**
> 它不产出预测，只在**已经存在的养殖观测数据**上回答三个问题：
> **① 这个干预（投喂量 / 密度 / 换水 / 增氧）的效应量是多少？
> ② 这个数字在什么条件下会不成立（需要多强的未测混杂才能推翻它）？
> ③ 效应在什么塘型 / 规模 / 品种上更大？**

### 2.2 依据的性质说明（三问，必须回答）

| 问 | 回答 |
|---|---|
| 这是**能力差异型**依据还是**空白型**依据？ | **能力差异型。** 核心能力＝因果推断的**方法工程**能力 + **识别有效性的自检纪律**（不声称因果推断理论能力） |
| **空白型依据占比**是多少？ | **0%**。本项目的论证不建立于"无人做"。第三轮预研已认证：T2「数据源型」5 个方向全不可行，"拿到公开数据"不能当创新点 |
| 是否声明了「未见披露 ≠ 不存在」？ | **是**，见《01-竞品与近邻尽调》第 0 节与本文件第 5.1 节 |

### 2.3 差异化落点

> **差异化的落点是「识别有效性的可审计化」，而不是「做因果推断」。**

| 对比对象 | 它做的是 | 本项目做的是 |
|---|---|---|
| 湛江科技学院「智擎虾塘」 | **预测 + 控制**：残饵识别 → 投喂决策 → 投饵机执行 | **识别 + 诊断**：不问"该投多少"，问"投喂量的效应是什么、这个判断在什么条件下失效" |
| 人保「粤海保」/ 湛江湾1号 | 给**观测预测**与预警 | 给**干预效应**估计与脆弱性边界 |
| 国内受控析因实验 | 随机化实验，**干净的因果结论**，但样本小、处理档位离散、离真实塘口远 | 在**真实塘口的观测数据**上做效应估计（需要识别假设与敏感性诊断） |
| 国内生产函数回归 / PSM-DID 成效评估 | 有因果意图但方法停在常规水平，未处理内生性 | 用 DML / DR / TMLE 等正交化估计，并**显式写出识别假设与推翻条件** |
| Yu et al. 2026（标题含 Causal）`[待核实]` | 溶氧的"因果因子"分析 + 预测建模 + 监测 | **范式不同**：本项目做**干预效应识别**（定义干预、构造反事实、量化混杂） |
| 浙江大学等元分析（*Aquaculture* 2026-01） | **文献层聚合**：214 项研究 / 2507 观测 / 108 物种的平均效应量 | **个体层条件效应**：给定这一塘的数据，效应多大、在什么条件下变大 |
| F3（模型评测基准与公平性审计） | 管**模型性能**的跨群体公平性 | 管**数据与识别假设**的有效性 |
| F14（可复现性审计） | 管结论**能不能重跑出来** | 管结论**是不是因果量** |
| E3（数据质量治理） | 管**输入数据对不对** | 管**从对的数据能不能推出因果结论** |
| E10（养殖 AI 可信性工程） | 管**输出结论的可信性**（输出端） | 管**输入数据的因果有效性**（输入端） |

### 2.4 外部验证基准表（本项目最重要的方法论设计）

| 对标问题 | 外部基准（准真值） | 对标规则 |
|---|---|---|
| 密度 → 生长/应激 的效应量 | 浙江大学等元分析（*Aquaculture* 2026-01，214 项研究 / 2507 观测 / 108 物种） | **方向一致 + 量级同阶**（不是数值相等） |
| 具体基准值 | SGR **−9.4%**、DFI **−13.6%**、FCR **+8.8%**、皮质醇 **+11.3%**、消化功能 **−15.5%**、同类相食率（杂食鱼）**+469.5%**、攻击行为频率 **−38.6%**；室内系统存活率 **+1.1%**、室外 **−6.3%** | 【引用】元分析原文摘要，经 2026-01 公开报道转载 |

> ⚠️ **规则的限制（必须同时写出）**：元分析聚合的是**受控实验**的效应，
> 本项目处理的是**观测数据**。两者的**估计目标不同**（ATE vs 条件效应），
> 混杂会使观测估计偏离。因此规则是「方向一致 + 量级同阶」，
> **在方向相反或量级差一个数量级以上时，优先怀疑本项目的方法**。

## 3. 能力与约束

### 3.1 具备的能力（可验证）

| 能力 | 证据 | 状态 |
|---|---|---|
| 因果推断方法工程能力 | `DoubleML` / `EconML` / `causalml` 等成熟开源实现可用；目标是可复现地跑通并正确诊断 | **需在 04-原型系统 中落实后才算成立** |
| 识别有效性自检纪律 | 「先假设、后估计、再诊断」的流程约束；每个结论必须附推翻条件 | 设计已定，**实现待做** |
| 合成数据可控真值实验 | 可构造已知因果结构的合成数据，量化标准方法的偏倚 | **本项目唯一能拿到真值的途径** |
| 跨域稳定性检验思路 | 继《蓝哨》GCI 的"跨域性能下降"度量，迁移为跨塘型/年份的效应稳定性检验 | 思路继承，**具体实现非本项目实测** |
| 同校算力可申请 | 本院「海创团队」实验室配 RTX3090（2006 年成立，30+ 专利、70+ 软著） | 需正式申请，**未落实** |

### 3.2 约束（**如实列出，不得包装成创新**）

| # | 约束 | 对项目的影响 |
|---|---|---|
| U-1 | **无养殖现场准入、无真实塘口数据** | 不得声称有塘口数据；主结果可能只能来自合成数据，须标 **【合成】** |
| U-2 | **无水产专业成员** | 混杂结构的判断可能出错；**依赖评审方（B-3）**，局限须写入报告 |
| U-3 | 经费约 1 万元 | 不得使用付费 API 做规模化实验；须走开源/本地路线 |
| U-4 | 无硬件条件 | 不得涉及硬件；同城学生队已占位 |
| U-5 | 同校已有强队（海创智渔）与真实塘口（徐闻科技小院） | 校内评审须论述差异化，且**不得声称拥有这些资源** |
| U-6 | 12 个月周期 | 范围必须窄；"平台"级表述不可交付 |
| U-7 | **因果推断方法本身零创新** | 全部价值压在"诊断与审计"上；**不得以"引入 DML/TMLE"为创新点** |

> **纪律**：约束**不是**创新点。任何把"我们没法做实验所以改做观测数据因果推断"写成立项理由的表述，
> 都属于「约束伪装成创新」，须删除。
> **特别注意**：本项目**极易**踩这条——"因为没有塘口所以只能做方法"就是典型的约束伪装成创新。

## 5. 表述红线（**本项目全文适用**）

### 5.1 三条否定性结论纪律

1. 禁用「均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 / 未检索到同类」；
   改用「**在所及范围内未见**」。
2. 否定性判断必须给出**举证范围与日期**，不得只写结论。
3. 「**未见披露 ≠ 不存在**」必须显式写出。

### 5.2 数据模式标注（强制）

每个数字/结论必须标注其模式：

| 标记 | 含义 |
|---|---|
| **【实测】** | 本项目自己跑出来的，可复现，原始数据在 `05-验证/` |
| **【合成】** | 由已知因果结构的合成数据产出，**不得表述为实测或真实养殖结论** |
| **【仿真】** | 仿真环境结果 |
| **【引用】** | 来自他人文献/报道，须给出来源 |
| **【元分析基准】** | 来自浙江大学等 *Aquaculture* 2026-01 元分析的外部对标值 |
| **【待核实】** | 未独立核实的二手材料 |

### 5.3 因果推断专属红线（**本方向特有，最容易踩**）

| # | 红线 | 为什么 |
|---|---|---|
| K-1 | **不得声称「揭示了因果」**。统一写「在给定识别假设下估计得到效应」 | 观测数据无法自证因果 |
| K-2 | **每个效应估计必须附「识别假设清单」与「推翻所需未测混杂强度」** | 无此两项的效应值不具备可审计性 |
| K-3 | **不得把效应估计表述为投喂/管理建议** | 本项目不做建议；误用风险极高 |
| K-4 | **不得声称能从数据"发现"因果结构（因果发现）** | 生态时序数据的 DAG 假设不可验证（C2 已淘汰，理由见选题论证第 4 节） |
| K-5 | **合成数据实验的结论不得外推为真实养殖结论** | 合成结构的设定本身是研究者的假设 |
| K-6 | **必须报告坏控制（bad control）检查**：调整变量集中不得含干预变量的下游结果 | 调整下游变量会引入新偏倚，且不报错 |

### 5.4 九条诚实性纪律

1. 数据模式标注（5.2）——**每个数字都要标**。
2. 核验状态标注——【已核实】/【子代理】/【待核实】。
3. 全称表述禁用（5.1）。
4. **未做的不得写成已做**。
5. **失败必须留痕**——失败实验、被淘汰方案一并保留（C1–C3 的淘汰理由必须留）。
6. 局限清单必须显式列出。
7. 修正记录公开（第 6 节）。
8. 无数据不产数——没有原始数据就不给结论。
9. 演示数据必须标明（合成数据不得伪装成真实塘口数据）。
