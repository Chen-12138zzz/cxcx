# STORY.md · F1 项目介绍

## ① 用户意图对齐

**目标受众**：校内评审 / 指导老师 / 大创答辩现场。听众具备基本科研素养，但不一定熟悉因果推断。
**核心目标**：讲完后希望听众**相信三件事** ——
① 这个方向真有一个具体的、能被追问的问题（不是"用 AI 做养殖"的空壳）；
② 我们已经用**真值已知的合成数据**把方法本身验证过（21/21 判定项），且**没有把合成结论外推成养殖结论**；
③ 我们**主动**交出了一条否定性结论 —— 它推翻了我们自己的一个核心设计。
**PPT 长度**：**12 页**（交付实测）。Hero 页 3 个（封面 P1 / P4 / P10），占 25%，落在 20–30% 区间。
**视觉调性**：学术严谨 / 证据驱动 / 蓝白克制 / 诚实留痕。
**内容边界**：
- **必讲**：问题是什么、和谁不一样、三陷阱、R-11 否定性结论、21/21 + 修正史、阻断项。
- **不讲**：具体算法推导、代码细节、预算与成员分工（`【待填】` 未落实）。
- **禁碰**：任何把合成数据效应量说成养殖结论的表述；任何"国内首个 / 没人做过"式表述；
  任何 `【待填】` 字段的编造填充。

**目录↔章节扉页契约（强制核对）**：目录（P1 之后紧随的目录页即 P1 本页）声明 **4 章**，
全篇**有且仅有 4 个 `type: section` 扉页**：P2（01）、P6（02）、P8（03）、P11（04）。
编号连续 01/02/03/04；扉页标题与目录条目**逐字一致** —— 见下方目录页与各扉页的 `title` 字段对照：

| 目录条目 | 编号 | 标题（逐字） | 对应扉页 |
|---|---|---|---|
| 1 | 01 | 问题与边界 | P2 |
| 2 | 02 | 方法设计 | P6 |
| 3 | 03 | 实验与结论 | P8 |
| 4 | 04 | 现状与下一步 | P11 |

> 注：本 PPT 实际 **12 页**：**封面 P1（hero）→ 目录 P2**，其后 P3–P12 依次为内容与收尾页（P12 = 小结／致谢，）。
> 为控制页数，目录与封面合并处理不可行（封面信息已满），
> 因此采用 **P1 封面 + P2 目录** 两页；另加 **P12 小结页**收尾。
> 扉页 4 个：**P2（01）、P6（02）、P8（03）、P11（04）**。Hero 页 3 个（P1 / P4 / P10），占 25%。

**Hero 页定位**：P1 封面（hero）、P4「三个陷阱」（hero，视觉高潮）、P10「否定性结论」（hero）。
任意两个 Hero 页之间至少间隔 1 个 Supporting 页 ✓（P1→P4 间隔 2 页；P4→P10 间隔 5 页）。

**rhythm 曲线**：
P1 peak → P2 transition → P3 valley → P4 **peak** → P5 valley →
P6 transition → P7 valley → P8 transition → P9 valley → P10 **peak** → P11 valley → P12 valley。

连续 valley 检查：P3、P5 之间被 P4（peak）打断 ✓；P7、P9 之间被 P8（transition）打断 ✓；
最长连续 valley = 2（无 ≥3）。

**非对称版式预算**：12 页中 **9 页用非对称版式**（75%）—— 远超 ≥40% 要求。
**对称版式预算**：仅 3 页用对称版式（P1b 目录、P2/P6/P8/P11 中取 P8 数据页、P10 居中金句）——
实际使用 3 页，其中 `N卡片横排` 使用 **0 次**（全篇上限 2 次）。
