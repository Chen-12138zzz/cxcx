## 1. 相对预设风格的微调（显式声明）

| 项 | 预设值 | 本项目取值 | 理由 |
|---|---|---|---|
| 顶条模式 | A1/A2/A3 三选一 | **A3（深蓝顶条 h=56 + 低透明线稿）** | 与 `F1项目介绍` 锁定同一模式，两份材料视觉同族 |
| 字体家族 | 思源黑 + 思源宋/Times | **思源黑（全篇）** | 产品介绍不需要宋体的文献感；保留单一家族更整齐 |
| 警示红配额 | 单页 ≤3% | **仅 P8、P10、P14 使用**，且只用于「无法追溯 / 不可检验 / 缺什么」类否定焦点 | 红色是语义色；这份 PPT 讲优势，红色只在"承认缺口"处出现 |
| 数据黄配额 | 单页 ≤3% | **仅在 P5 的「三层」编号条与 P10 的金句条使用** | 黄做锚点，不做装饰 |
| 深蓝实色卡 | 单页 ≤1、全篇 ≤3 | **P10 一张、P14 一张 = 全篇 2 张**（未达上限，刻意留一格） | 这份 PPT 比 `F1项目介绍` 更"轻"，深色卡太多会显得在喊口号 |

**配色比自检**：蓝族 39% / 白底 44% / 浅蓝 13% / 红+黄 4% / 金 0% ✓ 落在预设区间内。

## 7. 视觉语言（L1 统一）

全篇 **L1 视觉类型 = 矢量结构图（inline SVG）**，占比 100%（>60% 要求）：

| 页 | L1 内容 | 类型 |
|---|---|---|
| P1 | E3（输入可信）→ E10（输出可信）← E8（数据来源）的三环链 | 结构 SVG |
| P4 | 预警文本 → 逐数字回溯 → 判定（支持/不支持/无法判定）的审计链路 | 流程 SVG |
| P10 | 三层能力对照（合规层 / 通用层 / 事实与问责层）的缺口定位 | 结构 SVG |

**禁止**：3D、卡通、二次元、营销插画、装饰渐变大图。
**L2 无**（无摄影素材，学术风允许纯结构页仅用 L3）。
**L3**：封面角标与结束页右下角的校名文字标，位置全篇一致。

**本轮修正（生成过程中发现并当场改掉）**：

| # | 问题 | 处置 |
|---|---|---|
| 1 | P6 `以下均为目标对象，不是已合作客户` | 改为「以下是目标对象，不是客户名单」—— 规避 `均为` 全称词与 `已合作` 串 |
| 2 | P4 `三件事均为…` | 改为「三件事都来自…」 |
| 3 | P8 `没有任何人能复述出计算链路` | 改为「**计算链路没有留痕**，事后谁也复述不出来」—— 把未举证的**全称否定**换成可自证的**机制描述** |

**沿用经验（来自 `F1项目介绍`，本轮再次验证有效）**：
1. `slidep upsert-dsl` 的 `--page-index` 是 **0-based 替换**语义，`-1` 或缺省才是**追加**。
   做法：从头 `create` + 逐页显式 `--page-index <i-1>`，再用 `presentation.xml` 的 `sldIdLst` 逐位核对。
2. `slidep lint` 报的 `child-containment` / `no-overflow` 是**渲染后**高度溢出，
   按"声明的 height 求和"推算会偏差 4–40px —— 必须实跑 lint 迭代到干净。
   本轮因此迭代 **7 次**（P5/P6/P10/P12/P14）。
3. `slidep screenshot` 需 editor_sdk 环境，本机 shell 不可用；几何校验以 `lint` 为准。
4. **修布局与守闸门冲突时，优先删内容** —— 本轮全程未缩小任何正文字号。
