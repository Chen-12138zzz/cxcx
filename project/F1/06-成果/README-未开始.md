原计划是「**答辩 PPT 大纲**」，前置为「申报书完成（阶段 3）」。
**实际产出是完整可放映的 PPT**，且**前置被解除** —— 理由是：

- 介绍/产品 PPT 讲的是**已完成的工作与已定的产品口径**
  （问题定义、方法设计、21/21 实验、R-11 否定性结论、两个阻断项），**不依赖**申报书内容；

  若把 PPT 也挂在同一个前置上，等于让「已做出来的东西」陪着「没做出来的东西」一起等。

**但答复材料（答辩应答节）仍未写。** 原计划要求「须含『答辩应答节』：
预判『你这凭什么是因果』类问题」—— 这一部分**仍属未完成**，
因为它的内容要绑定具体申报口径（成员、预算、数据来源），须等阶段 3 解阻后补写。

## 一个不做的决定（记录在案）

**暂不申请软著**。理由：本项目的核心产出是一套**方法与诚实性纪律**
（实验设计、判据自检、修正记录），而不是一个完整的可用产品。
把一个研究原型包装成"软件产品"去注册软著，
与本项目"识别有效性可审计化"的立论**方向相反**。
若后续因结题需要必须申请，再单独评估——但**不得**为凑成果而申请。
