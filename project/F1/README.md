## 1. 这个项目在做什么

> 在**已经存在的养殖观测数据**上，回答三个问题：
>
> **① 这个干预（投喂量 / 密度 / 换水 / 增氧）的效应量是多少？**
> **② 这个数字多脆弱 —— 需要多强的未测混杂才能推翻它？**
> **③ 效应在什么塘型 / 规模 / 品种上更大？**

它**不产出预警、不做预测、不推荐投喂量**。它做的是**估计 + 有效性审计**：

```
观测数据 ──► ① 角色审计（谁是混杂 / 中介 / 碰撞）
             ② 正性诊断（有没有共同支撑）
             ③ 估计（DML-PLR / AIPW，双重稳健）
             ④ 剂量-反应曲线
             ⑤ 敏感性分析（E-value / 偏 R²）
             ⑥ 识别假设台账（A1–A6 逐条标注核验状态）
             ⑦ 报告守卫（不合格输出直接拦截）
                                     └──► 效应值 + 它的有效边界
```

### 差异化落点

**是「识别有效性的可审计化」，不是「做因果推断」。**

| 别人做的是 | 本项目做的是 |
|---|---|
| 「智擎虾塘」：残饵识别 → 投喂决策 → 投饵机执行（**预测 + 控制**） | 不问"该投多少"，问"投喂量的效应是什么、这个判断**在什么条件下失效**"（**识别 + 诊断**） |
| 受控析因实验：干净的因果结论，但样本小、处理档位离散 | 在**真实塘口的观测数据**上估计，并**显式写出识别假设与推翻条件** |
| 生产函数回归 / PSM-DID：有因果意图，方法停在常规水平 | DML / DR / TMLE 正交化估计 + 敏感性分析 |

**立项依据类型：能力差异型。空白型依据占比 0%。**
（这是纪律 —— 第三轮预研已认证"没人做"不能当立项理由。）

## 3. 最重要的结论：一个**否定性**的发现

> **在「全局等频箱 × 分位协变量层」框架下，
> 连续干预的「机制性（结构性）正性违背」在原理上无法被诊断。**

这条结论**推翻了我们自己诊断模块的一个核心设计**，
完整定位过程见 [`05-验证/修正记录.md`](05-验证/修正记录.md) 的 **R-11**。

### 怎么发现的（三重独立证据 + 决定性实验）

| 步骤 | 做法 | 结果 |
|---|---|---|
| 异常信号 | 20 个种子、**无任何真实违背** | **20/20 全报 `structural`** ← 假阳性率 100% |
| 第一反应（错） | 调阈值（改成"每箱期望样本数"阈值） | **仍然 20/20 报** |
| 证据 ① | 扩样本 n: 3000 → 48000 | 空箱层 4 → **0**（若是机制性，扩样本不可能消失） |
| 证据 ② | **置换零模型**（把 T 随机重排，使 T ⟂ X） | gap 层从 `4,3,5,2,1` → **`0,0,0,0,0`** |
| 证据 ③ | 空箱位置直方图 | 几乎全在极端箱 ⇒ `层样本量/箱数` 的**均匀假设**不成立 |
| **决定性** | 人为**硬截断支撑集**（低箱概率**恰为 0**） | `[7,2,1,1,0,0]` —— **同样收敛到 0** |

**⇒ 连"概率恰为 0"都测不出来 ⇒ 是框架的分辨率问题，不是阈值问题。**

### 修复方式：改成诚实四分类

| 判定 | 含义 | 样本量敏感？ |
|---|---|---|
| `sparse` | 有空箱，且每箱期望样本数 **< 阈值** ⇒ 可由有限样本充分解释 | 敏感 |
| `undetermined` | 有空箱，但期望**已充足** ⇒ **本诊断没有能力**解释成因 | 敏感 |
| `narrow` | 无空箱，但层内 T 支撑明显窄于全局 | **不敏感** |
| `ok` | 无空箱，且各层支撑宽度可接受 | — |

★ **关键纪律**：`undetermined` **不是**"结构性"的同义词，
它只诚实地说"在这个样本量与分层方案下判不了"。
要定性需借助**本诊断之外**的证据（场景知识、离散 T、或制度约束记录）。

### 由此提炼出的四条判据设计自检

1. **零假设自检** —— 在"答案已知为否"的极端情形上，它会不会报阳性？
2. **动态范围自检** —— 现象真实存在时，这个判据的分辨率够看见它吗？
3. **退化情形自检** —— 在这个档位上，两种方法**本来就应该**相同吗？
4. **"恒不通过"自检** —— 一个从不通过的判据，很可能是它根本没在工作。
