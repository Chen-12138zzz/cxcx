## 1. `synth` —— 数据层

### 1.1 `generate()`

```python
generate(n: int = 800,
         u_strength: float = 0.0,
         nonlinear: bool = True,
         positivity_violation: float = 0.0,
         seed: int = 20260920) -> pd.DataFrame
```

| 参数 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `n` | int | 800 | 样本量（塘·周期 数） |
| `u_strength` | float | 0.0 | **未测混杂强度开关**。0 = U 不影响 T；1 = 按 `C_T_ON_U` 生效。可取 >1 做压力测试 |
| `nonlinear` | bool | True | 是否启用 `T²` 项与 `T×WQ` 交互项 |
| `positivity_violation` | float | 0.0 | 正性违背强度 0–1；在低温大塘层强制抬高 T |
| `seed` | int | 20260920 | 随机种子（**必须固定并记录**） |

**返回**：`DataFrame`，列见下表；同时 `df.attrs` 携带真值与标准化常数。

| 列 | 角色 | 备注 |
|---|---|---|
| `pond_area` / `pond_depth` / `pond_type` / `season_temp` | 协变量 | 预处理 + 季节 |
| `feed_rate` | 干预 T（连续） | 标准化 |
| `feed_high` | 干预 T（二值） | 按中位数切，切点在 `attrs["cut"]` |
| `water_degrad` | **中介** | 受 T 影响且影响 Y |
| `fcr` | **碰撞** | 分子含 T、分母含 Y |
| `growth` | 结果 Y | 标准化（★ 真值须同尺度） |
| `shrimp_appetite` | **未测混杂 U** | 仅诊断用，**不得入调整集** |
| `_true_ate` / `_true_cate` | 真值 | 仅评估用，**不得入模型** |

**`df.attrs` 契约**：

| 键 | 类型 | 用途 |
|---|---|---|
| `cut` | float | 二值化切点 |
| `treat_high_mean` / `treat_low_mean` | float | 口径换算 `d_t` |
| `wq_mu` / `wq_sd` | float | WQ 标准化常数（真值计算须共用） |
| **`y_sd`** | float | Y 标准化常数（★ 真值换算必需） |
| `nonlinear` / `u_strength` / `positivity_violation` / `n` / `seed` | — | 可复现性与审计 |

**保证**：

- 同 `seed` 两次调用**逐位相同**（INV-1）；
- 不同 `seed` 产生不同数据；
- `_true_ate` / `_true_cate` 为**常数列**。

**⚠️ 尺度约定（必须遵守）**：

`growth` 是**标准化后**的 Y。因此：
- `_true_ate` **也在标准化尺度上**；
- 手工计算真值时必须除以 `df.attrs["y_sd"]`。

漏掉这个换算会造成**与样本量无关的常数偏倚**（本项目实际发生过，见 `修正记录.md` R-2）。

### 1.2 `compute_truth()`

```python
compute_truth(df, cut, high, low, nonlinear, wq_sd, y_sd=1.0)
    -> tuple[float, np.ndarray]
```

**返回**：`(ate_true, cate_array)`。

**公式**：

```
θ(t) = C_Y_ON_T·t + C_Y_ON_WQ·(C_WQ_ON_T/wq_sd)·t
       + C_Y_T_SQUARED·t² + C_Y_T_WQ_INTER·(C_WQ_ON_T/wq_sd)·t²
ate_true = [θ(high) − θ(low)] / y_sd
```

**⚠️ 两个不可省略的因子**：

| 因子 | 省略后果 |
|---|---|
| `wq_sd` | 真值差 `1/wq_sd ≈ 1.95` 倍（R-1） |
| `y_sd` | 真值差 `sd(y) ≈ 1.19` 倍，表现为 −0.044 常数偏倚（R-2） |

## 2. `estimators` —— 估计层

### 2.1 `CausalEstimate`（返回值契约）

| 字段 | 类型 | 说明 |
|---|---|---|
| `point` | float | 点估计 |
| `se` | float \| None | 标准误 |
| `ci_low` / `ci_high` | float \| None | 95% CI |
| **`contrast_kind`** | str | `"slope"` 或 `"two-point"` |
| `t_ref` | float \| None | two-point 的参照 T 取值 |
| `t_at` | float \| None | two-point 的目标 T 取值 |
| `method` | str | 方法名 |
| `notes` | list[str] | 备注 |
| `assumptions` | list[str] | 依赖的假设编号（默认 A1–A6） |

**方法**：`rescale_to_twopoint(d_t) -> CausalEstimate`

```
two_point = slope × d_t
```

**⚠️ 仅在效应近似线性时有效**；非线性强时会引入误差，须在报告中标注。

### 2.2 四个估计器

| 函数 | 估计对象 | `contrast_kind` | 用途 |
|---|---|---|---|
| `estimate_naive(df)` | 不做调整 | `slope` | 展示"完全不调整"的代价 |
| `estimate_adjusted_ols(df, covariates)` | OLS + 协变量 | `slope` | 常规做法的基准 |
| `estimate_ate_continuous(df, covariates, engine)` | DML-PLR（正交化 + 交叉拟合） | `slope` | **主估计器** |
| `estimate_ate_binary(df, covariates, engine)` | AIPW（双稳健） | `two-point` | 二值干预的对照 |

**`engine` 取值**：

| 值 | 行为 |
|---|---|
| `"auto"` | 优先 `doubleml`，失败回落自实现 |
| `"doubleml"` | 强制用 `doubleml` 库 |
| `"manual"` | 强制用自实现的 PLR |

**⚠️ `doubleml ≥ 0.9` 的签名差异**：`DoubleMLPLR` 使用 `ml_l`（E[Y|X]）与
`ml_m`（E[D|X]），而 `DoubleMLIRM` 用 `ml_g`。

**禁止事项**：

| 禁止 | 后果 |
|---|---|
| 把 `fcr` 放进 `covariates` | 打开后门通路，效应被放大（实测约 4.5 倍，见 exp3） |
| 把 `shrimp_appetite` 放进 `covariates` | 违反"U 不可得"的设定，人为消除混杂 |
| 把 `_true_ate` 放进模型 | 真值泄漏 |
| 跨 `contrast_kind` 直接比较 | 数值不可比 |

## 3. `dose_response` —— 剂量-反应层

### 3.1 `DoseResponseCurve`

| 属性 | 类型 | 说明 |
|---|---|---|
| `grid` | ndarray | 评估网格 |
| `theta` | ndarray | 累计效应 `θ(t)` |
| `se` | ndarray | 逐点标准误 |
| **`beta`** | ndarray | 多项式系数（路径 A） |
| `beta_se` | ndarray | 系数标准误 |
| `r2_holdout` | float | 留出 R² |
| **`is_smooth`** | bool | 平滑性判定 |
| **`smoothness_ratio`** | float | `max|Δ²θ| / ptp(θ)` |

**方法**：

| 方法 | 签名 | 说明 |
|---|---|---|
| `at` | `(t) -> (theta, se)` | 单点取值 |
| `marginal_effect` | `() -> ndarray` | **解析**边际效应 `dθ/dt` |
| `two_point_ate` | `(t_high, t_low) -> (ate, se)` | 两点差 |
| `to_frame` | `() -> DataFrame` | 导出 |

**平滑性判据**（v3 定稿）：

```
is_smooth = (max|Δ²θ| / ptp(θ)) < SMOOTH_REL_TOL   # SMOOTH_REL_TOL = 0.02
```

实测判别力：多项式路径 `0.0021–0.0038`，GBR 路径 `0.16–0.42`，
**相差 30–197 倍**。

> ⚠️ 该判据经**三次迭代**才定稿。前两版失效原因见 `修正记录.md` R-10。

### 3.2 两条估计路径

| 函数 | 方法 | 用途 | 实测对真值 MAE |
|---|---|---|---|
| `estimate_dose_response`（**路径 A**） | 多项式可加基（`degree=3`） | **主结果** | **0.0151** |
| `estimate_dose_response_robust`（**路径 B**） | GBR 直接拟合 | **仅形状参照** | 0.1806 |

**⚠️ 路径 B 的水平值不可用于比较** ——
它拟合 `E[Y|T,X]` 的原始面，**未正交化**，其水平值包含全部协变量的贡献。
两路径的**水平差本来就存在**，与网格宽度无关。
可比较的只有**形状**（例如是否单调、拐点位置）。

### 3.3 `grid_quantile` 参数

| 签名 | 默认 |
|---|---|
| `estimate_dose_response(..., grid_range=None, grid_quantile=0.10)` | 0.10 |

**作用**：网格取 T 的 `[q, 1−q]` 分位区间，避免三次多项式在稀疏尾部放大不稳定。

**实测依据**（路径 A 对真值 MAE，seed=11）：

| `grid_quantile` | 网格范围 | 对真值 MAE |
|---|---|---|
| 0.02 | [−2.082, +2.047] | 0.0212 |
| 0.05 | [−1.655, +1.636] | 0.0133 |
| **0.10** | [−1.296, +1.275] | **0.0081** |
| 0.15 | [−1.044, +1.032] | 0.0053 |
| 0.20 | [−0.839, +0.837] | 0.0034 |

误差随网格收窄**单调下降**（同时端点标准误与中段之比从 7.13× 降到 5.75×）。
默认取 **0.10** 是精度与外推范围的折中：更窄更准，但覆盖的 T 范围更小。

### 3.4 `monotonicity_report()` 返回结构

|---|---|---|

## 4. `diagnostics` —— 诊断层

### 4.1 `diagnose_positivity()`

```python
diagnose_positivity(df, t_col="feed_rate", covariates=None,
                    n_boxes=5, strata_per_covariate=3,
                    min_count=5, min_stratum_size=10,
                    min_expected_in_box=None, seed=...) -> PositivityDiagnosis
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `n_boxes` | 5 | 每层的 T 分箱数 |
| `strata_per_covariate` | 3 | 每协变量的分层数（4 个协变量 → 3⁴ = 81 层） |
| `min_count` | 5 | 单箱最小样本数 |
| `min_expected_in_box` | `None` → `max(3.0, min_count)` | **★ 该箱期望样本数阈值** |

**`PositivityDiagnosis` 字段**：

| 字段 | 说明 |
|---|---|
| `n_boxes` | 总箱数 |
| `n_strata_sparse_gap` | **稀疏**空箱数（期望样本数不足 → 可由有限样本解释） |
| `n_strata_undetermined` | **空箱但期望充足**的层数（★ **本诊断无能力定性**，见下） |
| `median_expected_in_box` | 期望样本数中位（诊断用） |
| `undetermined_fraction` | 上述层占比 |
| **`verdict`** | `ok` / `sparse` / `narrow` / `undetermined` |

> ⚠️ **字段更名（第三版，2026-09-20）**：原 `n_strata_struct_gap` / `struct_gap_fraction`
> 已更名为 `n_strata_undetermined` / `undetermined_fraction`。旧名保留为
> `@property` 别名以兼容既有调用，但**语义已变更** ——
> 旧名声称"结构性"，新名只声称"本诊断无法定性"。见《修正记录》R-11。

**核心判据**：

```
exp_in_box = stratum_size / n_boxes
enough     = exp_in_box >= min_expected_in_box
如果 箱为空 且 not enough → sparse        （可由有限样本充分解释）
如果 箱为空 且 enough     → undetermined  （★ 本诊断判不了，不是"结构性"）
如果 无空箱 且 存在层内 IQR 比值 < 0.5 → narrow
否则 → ok
```

**⚠️ 已知能力上限（重要，第三版修正）**：

本诊断**不再主张**能判定"结构性/机制性"正性缺失。此前版本（第 2 版）认为
"期望充足却仍空箱 ⇒ 抽不到 ⇒ 结构性"，**已被本项目自己的验证推翻**
（见《修正记录》R-11）：

| n | 无任何违背时 gap 层 | 人为硬截断支撑集后 gap 层 |
|---|---|---|
| 3000 | 4 | 7 |
| 12000 | 0 | 1 |
| 48000 | 0 | **0** |

两者放大样本后**同样收敛到 0** ⇒ 在「全局等频箱 × 分位协变量层」框架下，
空箱存在与否**无法区分**抽样波动与机制缺失（分辨率被 `n/405` 限死）。
因此：
- 无违背时**仍会出现 `undetermined`**（如 n=1200/54 层出现 4 个）——
  这是**如实报告"判不了"**，不是 bug；
- 要定性需借助本诊断**之外**的证据：场景知识、离散型 T、制度约束记录。

### 4.2 `audit_adjustment_set()`（静态，不需数据）

```python
audit_adjustment_set(covariates, roles=None) -> dict
```

**返回**：`{"n": int, "pass": bool, "violations": [{"变量": str, ...}]}`

**角色表 `KNOWN_ROLES`**：

| 变量 | 角色 | 政策 |
|---|---|---|
| `water_degrad` | `mediator` | **禁止**入调整集（若目标是总效应） |
| `fcr` | `collider` | **禁止**入调整集（任何情况下） |
| `shrimp_appetite` | `unmeasured_confounder` | **禁止**（设定上不可得） |

**用途**：在研究开始前就能判定调整集是否合规，**不需要数据**。

### 4.3 `check_bad_control()`（动态，需数据）

对每个候选变量报告：

| 字段 | 说明 |
|---|---|
| `candidate` | 变量名 |
| `role` | 角色（来自 `KNOWN_ROLES` 或推断） |
| `partial_r2_with_t` | 该变量对 T 的偏 R² |
| `partial_r2_with_y` | 该变量对 Y 的偏 R² |
| `compliant` | 是否合规 |

**⚠️ 偏 R² 只作"提示人工复核"用**，不自动判定角色：
本项目中 `water_degrad` 的偏 R²(Y) 低至 `+0.0008`（u=0.6 时），
若单看这个数字会误判为"不重要"，但它确实是中介。

### 4.4 `e_value()`

```python
e_value(est, se=None, ci_low=None, ci_high=None, rare=True) -> dict
```

| 返回键 | 说明 |
|---|---|
| `e_value_point` | 把点估计拉到 0 所需的混杂强度 |
| `e_value_ci` | 把 CI 近零端拉到 0 所需的强度（**应报告这个**，更保守） |
| `rr_approx` | 转换后的近似 RR |
| `note` | 尺度转换说明（**必须随结果展示**） |

**公式**：

```
E = RR + sqrt(RR·(RR − 1))
RR ≈ exp(0.91 × |est|)      ← 对连续 Y 的近似转换（须标注为近似）
```

**⚠️ 性质**：`e_value_ci ≤ e_value_point` 是**定义性质**，若不成立则实现有误
（本项目把它写成 INV/实验判据 F2 来反向验证）。

### 4.5 `cih_sensitivity()`

```python
cih_sensitivity(theta, se, dof, r2_treated, r2_outcome,
                ratios=(0.0, 0.5, 0.8, 1.0), n_grid=60) -> SensitivityResult
```

**`SensitivityResult` 字段**：

| 字段 | 说明 |
|---|---|
| `theta` / `se` / `dof` | 输入 |
| `r2_treated` / `r2_outcome` | 已观测因素的解释力 |
| **`robust_curve`** | DataFrame，列 `rho_T` 与 `ry_for_<ratio>` |
| `partial_r2_benchmarks` | 与已观测变量的对比基准 |
| `notes` | 说明列表 |

**方法**：`breakdown_at(target_ratio=0.0) -> dict`

**⚠️⚠️ `breakdown_at` 的已知缺陷（必须知道）**：

它挑"`ry_for_0.00` 最接近 `r2_outcome` 的那一行"，但 `ry_for_0.00` 在参数区间上
被 `np.clip(·, 0, 1)` **顶到 1.0 而饱和**，于是它**恒返回第 0 行**，
给出 `ρ_Y ≈ 0.9999999999`。

这个值**在浮点上 < 1**，会让"必须 < 1"的判据**假通过**。
本项目在 exp5 首轮就踩了这个坑。

**正确用法**：读 `robust_curve` 的 `rho_T` 中位处的 `ry_for_0.00`
（实测 0.22–0.24，有意义）。

**⚠️ 该实现是近似参数化**，不是 Cinelli–Hazlett 的严格界。
输出**不得**表述为"调整后的置信区间"（红线 K-3）。

### 4.6 `stress_test_bias()`

```python
stress_test_bias(est_fn, u_levels=(0.0,0.2,...,1.0),
                 n=2000, seed=..., contrast="slope") -> pd.DataFrame
```

**返回列**：`u_strength` / `true` / `est` / `bias` / `abs_bias` /
`rel_bias` / `se` / **`bias_in_se`**（偏倚除以标准误）

**`bias_in_se` 是本项目最有说服力的输出**：它把偏倚换算成"几个标准误"，
实测从 u=0 的 `0.039` 升到 u=1.2 的 `11.67`。

**⚠️ 结论仅适用于合成结构**，不得外推为真实塘口（红线 K-5）。

## 5. `ledger` —— 台账层

### 5.1 `Assumption`

| 字段 | 说明 |
|---|---|
| `id` | 编号（A1–A6） |
| `name` | 名称 |
| `statement` | 陈述 |
| `evidence_level` | `untestable` / `testable` / `partially_testable` |
| `diagnostic` | 诊断方法 |
| `evidence_file` | 证据文件路径 |
| `status` | `unverified` / `partially_verified` / `violated` / `not_applicable` |
| `diagnostic_ran` | 是否实际跑过诊断 |
| `must_disclose` | 是否须在报告中显著披露 |

**`__post_init__` 守卫规则**（构造即检查）：

| 规则 | 违反后果 |
|---|---|
| `status` 必须在 `VALID_STATUS` 内（**不含 `verified`**） | `ValueError` |
| `evidence_level == "untestable"` 时 `status` 不得为 `partially_verified` | `ValueError` |
| `status ∈ {partially_verified, violated}` 时 `diagnostic_ran` 必须为 `True` | `ValueError` |

**为什么守卫放在 `__post_init__`**：初版只在 `assert_ledger_valid()` 里检查，
而构造 `Assumption` 不会自动调用它，导致 4 种非法写法中有 2 种**未被拒绝**。
移入 `__post_init__` 后 4/4 全部拒绝。

### 5.2 六条假设

| 编号 | 名称 | Evidence level | 可否诊断 |
|---|---|---|---|
| **A1** | 无未测混杂 | `untestable` | **不可检验**，只能做敏感性分析 |
| A2 | 正性 / 重叠 | `testable` | 可（倾向得分分布） |
| A3 | 一致性 / SUTVA | `partially_testable` | 部分 |
| A4 | 无中介调整 | `testable` | 可（静态审计） |
| A5 | 无碰撞调整 | `testable` | 可（静态审计） |
| A6 | 干预为实际值 | `testable` | 可（数据结构检查） |

**A1 是本项目最脆弱处**，也是全部敏感性分析的动机。

## 6. `report` —— 报告层

### 6.1 `ReportGuard`

| 方法 | 说明 |
|---|---|
| `check(cond, item, detail)` | 记录一项检查结果 |
| `require(cond, item, detail)` | 不满足则**抛异常** |
| `to_frame()` | 导出检查记录 |

### 6.2 渲染函数

| 函数 | 作用 | 守卫行为 |
|---|---|---|
| `render_estimate_table(estimates, true_value, mode)` | 估计表 | 标注数据模式 |
| `render_dose_response_report(...)` | 曲线报告 | **不平滑时拦截边际效应输出** |
| `render_sensitivity_report(e_val, sensitivity, guard)` | 敏感性报告 | **无 E-value 时抛异常** |
| `render_assumption_section(ledger)` | 假设台账节 | — |
| `render_provenance(script, params, mode, extra)` | 溯源信息 | — |

### 6.3 数据模式标记（强制）

`_mark_mode(mode)` 在输出中插入模式标记：

| 标记 | 含义 |
|---|---|
| **【实测】** | 本项目自己跑出，可复现 |
| **【合成】** | 来自 `synth.py`，**不得表述为真实结论** |
| **【引用】** | 来自他人文献 |

### 6.4 缺失值约定

| 情况 | 输出 |
|---|---|
| 该指标未计算 | `"—"`（破折号） |
| **禁止** | 留空 / 填 `0` / 填估计值 |

**理由**：报告里一个"看起来合理"的假数字比显式空缺危险得多。

## 7. 错误处理约定

| 场景 | 行为 |
|---|---|
| 调整集含碰撞 / 中介 | **不抛异常**，由 `audit_adjustment_set` 报违规；由调用方决定 |
| 曲线不平滑 | **拦截**边际效应输出（不抛异常，但该节输出"不可用"） |
| 无 E-value 可算 | **抛异常**（不留空、不填 0） |
| 估计器不收敛 | 捕获异常，在结果里记 `method_error`，**不静默丢弃** |
| `doubleml` 缺失 | `engine="auto"` 时回落自实现；`engine="doubleml"` 时报错 |

## 9. 接口使用示例（可直接运行）

```python
import sys
sys.path.insert(0, "src")

import synth
from estimators import estimate_ate_continuous
from diagnostics.positivity import diagnose_positivity
from diagnostics.bad_control import audit_adjustment_set
from diagnostics.sensitivity import e_value, stress_test_bias
from ledger import default_ledger, ledger_to_md

COV = ["pond_area", "pond_depth", "pond_type", "season_temp"]

# 1) 生成数据（含真值）
df = synth.generate(n=3000, u_strength=0.6, nonlinear=True, seed=11)
d_t = df.attrs["treat_high_mean"] - df.attrs["treat_low_mean"]
true_slope = float(df["_true_ate"].iloc[0]) / d_t

# 2) 估计（注意 contrast_kind == "slope"）
r = estimate_ate_continuous(df, covariates=COV, engine="manual")
print(f"θ̂={r.point:+.4f}  SE={r.se:.4f}  口径={r.contrast_kind}")
print(f"真值(同口径)={true_slope:+.4f}  偏倚={r.point-true_slope:+.4f}")

# 3) 诊断
diag = diagnose_positivity(df, covariates=COV)
print(f"正性判定：{diag.verdict}（无法定性的空箱 {diag.n_strata_undetermined} 个）")

audit = audit_adjustment_set(COV)
print(f"调整集合规：{audit['pass']}")

bad = audit_adjustment_set(COV + ["fcr"])
print(f"加入 fcr 后合规：{bad['pass']}  违规={[v['变量'] for v in bad['violations']]}")

# 4) 敏感性
ev = e_value(r.point, se=r.se, ci_low=r.ci_low, ci_high=r.ci_high)
print(f"E-value：点={ev['e_value_point']:.3f}  CI端={ev['e_value_ci']:.3f}")
print(f"  {ev['note']}")

# 5) 台账
print(ledger_to_md(default_ledger()))
```

**期望输出（数值随 seed 变化，量级应一致，已实测核对）**：

```
θ̂=+0.3593  SE=0.0209  口径=slope
真值(同口径)=+0.2174  偏倚=+0.1419
正性判定：undetermined（无法定性的空箱 N 个）   ← ⚠️ 见下方说明
调整集合规：True
加入 fcr 后合规：False  违规=['fcr']
E-value：点=2.119  CI端=2.006
```

> 上表中 `N` 与判定值请以**实跑为准**（`n=3000` 下通常为 `undetermined`，
> 层数 54 时约 1–5 个空箱层）。本文件第三版不再给出固定的假阳性数字。

**注意 1**：偏倚 `+0.1419` 是 `u_strength=0.6` 下**未测混杂应有的表现**，
全部数值均来自**合成结构**，不得外推真实塘口。

**注意 2（重要，不得省略）**：上面 `positivity=undetermined` **不是**正性违背，
也**不是**"结构性缺失"。本次调用 `positivity_violation=0.0`（生成机制无违背）。

⚠️ **本注意项在第三版已重写**。原文写的是：
> "这是**已知的假阳性**……成因：期望样本数紧贴阈值，判定落入**不稳定区**。
> 核实方法：跑 20 个 seed，若 `verdict` 在 `ok` 与 `structural` 间**跳变**，
> 即确认是判定不稳。"

**这个根因判断已被实测推翻**：跑 20 个不同 seed 后，**20/20 全部报
`structural`**（不是跳变）。进一步用置换零模型（T 随机重排，正性必然成立）
验证，5/5 轮空箱层数降到 0；再把人 n 放大到 48000，空箱**同样消失**，
连"人为硬截断支撑集"的情形也不例外。
⇒ 真正的结论是：**该框架下的空箱计数无法区分稀疏与结构性**（《修正记录》R-11）。

因此第三版的做法是**删掉 `structural` 这个类别**，
改为 `undetermined` —— 它如实表示"本诊断判不了"。
**在报告中引用 `verdict` 时必须同时报告 `median_expected_in_box`
与 `verdict` 的取值区间**，否则读者无法判断该诊断是否有分辨力。
