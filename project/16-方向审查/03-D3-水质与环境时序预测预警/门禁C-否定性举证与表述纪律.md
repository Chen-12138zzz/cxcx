## 2. 本方向特有的表述陷阱

D3 最大的表述风险是**重演《蓝哨》的措辞**：把「预警系统还没人做好」写成立项理由。
竞品分析表对此已有明确判断，必须照抄采纳：

> 「**直说：预警本身不是空白，学生队只能做可信性补位，独立立项论证薄弱，建议并入 E3/E10 的统一主线。**」

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 预警系统尚不完善 | 删除——这是主观判断而非举证 |
| 国内首个 / 首创 | （删除） |
