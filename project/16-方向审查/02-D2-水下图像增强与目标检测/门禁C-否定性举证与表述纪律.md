## 2. 本方向特有的表述陷阱

D2 最易出现的违规表述是原文中的 **「本簇里唯一纯软件可独立切入的方向」**——
这句话暗示了别人不能做软件、只有我们能，但事实上**深之蓝等已有成熟的纯软件全栈方案**，且本校团队也能做。
这是把「我们没有硬件条件」包装成了「我们选择只做软件」。

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 完全空白 / 尚属空白 / 国内首个 / 首创 | （删除或改为在所及范围内未见披露） |
| 本簇唯一纯软件可独立切入 | 删除——与事实不符 |
