## 2. 本方向特有的表述陷阱

E2 最大的陷阱是**用「数字孪生」这个热门词掩盖交付物不清**。
「数字孪生」需要实时数据流与三维建模，**1 万元预算无法支撑**。
若在申报书中使用该词却无法交付，会被直接质疑。

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 数字孪生平台（当无法真正实现实时同步时） | 如实用「数据看板」或「分析工具」 |
| 国内首个养殖数字孪生 | （删除） |
| 填补平台空白 | 删除——平台不空白 |
