## 2. 最强近邻：湛江科技学院「智擎虾塘」（已核实）

| 项 | 内容 |
|---|---|
| 主体 | 湛江科技学院学生团队（**同城、同为本科生队伍**） |
| 时间 | 2026-05 公开报道 |
| 技术① | 多参数融合水下监测浮标（浑浊水体下采集溶氧/pH/水温 + **精准识别残饵数量**） |
| 技术② | **基于残饵识别的双模型智能决策算法**（按需投喂、精准控料） |
| 技术③ | 物联网协同执行模块（对传统投饵机的**低成本智能化改造**） |
| 指标 | 投喂误差 <5%、饲料浪费降低 15%+、综合成本约为国际同类产品三分之一 |
| 成果 | **已有多项发明专利、软件著作权**；计划年内新增 20 家以上合作养殖户 |
| 来源 | 中国日报网 2026-05-11、中国物联网 2026-05-11、南方日报 2026-06-25 |

### 为什么这条判死 D1

1. **同为本科生队伍**——"学生做不了"这条退路不存在。
2. **已有 7 家养殖户试点**——"学生拿不到塘口"这条退路不存在。
3. **已有专利与软著**——"学生出不了成果"这条退路不存在。
4. **同城**——评委大概率知道，甚至可能就是同一批评审专家。
5. **技术路线与 D1 高度重合**——残饵识别 + 投喂决策，正是 D1 的核心内容。

**D1 原本打算做的事，这支队伍已经做完了，且做得比我们更完整（他们还有硬件和塘口）。**

## 3. 我方机会四问（转录自竞品分析表，供对照）

1. **做什么**：边缘端轻量化摄食强度识别 + 不确定性量化工具包，输出「投喂建议 + 置信度 + 低置信回退」
2. **怎么竞争**：对智擎虾塘——它给投喂量，我给"投喂量 + 置信度 + 回退"
3. **创新点**：把「输出可信性」当卖点（竞品公开材料未见披露）
4. **原文标注的唯一窄口**：「**但前提是拿到湛江本地浊度塘口数据，否则只能停在公开数据集复现——这也是本方向唯一的窄口。**」

## 4. 我方机会四问的自我检验（**这一节是本文件的核心**）

| # | 原设问 | 检验结论 |
|---|---|---|
| 1 | 做「投喂建议 + 置信度 + 回退」 | **该功能与 E10 完全同构**。这不是 D1 的差异化，是 E10 的。放在 D1 名下会导致两个方向内容重复 |
| 2 | 与智擎虾塘的差异是"加置信度" | **这个差异在 D1 语境下不成立**：评委会问"你不做投喂，只做置信度，那你为什么不直接做 E10" |
| 3 | 输出可信性是卖点 | **同上，卖点属于 E10，不属于 D1** |
| 4 | 窄口是"本地浊度塘口数据" | **该前提已确认不成立**：本项目无养殖现场准入保证，而智擎虾塘已有 7 户 |

**结论：D1 无法独立成立。它唯一的活路是"降级为 E10 的一个场景实例"。**
