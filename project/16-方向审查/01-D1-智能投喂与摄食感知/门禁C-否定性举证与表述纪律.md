## 2. 该方向特有的表述陷阱

D1 最容易出现的违规表述是**"同城学生队做的是硬件，我们做算法"**。
这类表述的问题在于：
1. 暗示了"硬件才是主体、算法是补位"——但智擎虾塘的**双模型决策算法本身就是核心成果**；
2. 把"我们没有硬件条件"写成了"我们选择不做硬件"，属于**约束伪装成创新**。

**禁用表述（本方向适用）**：

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 完全空白 / 尚属空白 | 在所及范围内未见披露 |
| 国内首个 / 首创 | （删除） |
| "同城团队只做硬件" | 删除——与事实不符 |
| "我们聚焦算法层"（当实际是无硬件条件的委婉说法时） | 如实写：**本项目无硬件条件** |
