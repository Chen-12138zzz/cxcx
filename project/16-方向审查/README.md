# 16 方向三门禁审查工作区

## 这是什么

对湛江对虾养殖 AI 类大创**全部 16 个候选方向**（D1–D6、E1–E10）
执行同一套审查方法后留下的完整证据链。

审查动因：上一轮「主推 D1 + D5」的结论被本地竞品调研推翻——
**D1 已被同城学生团队「智擎虾塘」成套占位**。既然 D1 会翻车，
其余 15 个方向就不能凭印象保留，必须逐个过一遍同样的检查。

## 方法：阶段 0 三门禁

| 门禁 | 名称 | 核心问题 | 通不过意味着 |
|---|---|---|---|
| A | 近邻尽调 | 这件事**在五级半径内**有谁在做？ | 别人已经做了 |
| B | 能力差异检验 | 我凭什么做得成？为什么具备该能力的人没做？ | 我们根本做不了 |
| C | 否定性举证 | 我的否定性结论能否被举证？ | 立论方式本身不成立 |

### 门禁 A 的五级半径（不许跳级）

1. **本校**（广东海洋大学）——最容易被忽略，也最致命
2. **同城学生团队**——在大创场景下比大公司更致命
3. **同城公司**
4. **国内公司 / 高校**
5. **国外 / 学术文献**

> 经验修正：查「谁在做同一件事」的优先级应为
> **同校 → 同城学生团队 → 同城公司 → 国内公司 → 学术文献**。
> 本项目上一轮漏了同城公司，本轮差点漏掉同城与本校学生团队。

### 门禁 B 的三问

1. 我具备什么别人不具备的能力？
2. 具备该能力的人为什么没做？
   ——答案必须是**动机不匹配**或**粒度不匹配**，**不能是「他们没想到」**。
3. 不具备该能力的人做得了吗？

### 门禁 C 的表述纪律

禁用：均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 /
未检索到同类 / 国内首个 / 首创。

替代：「**在所及范围内未见**」。

强制附带：**未见披露 ≠ 不存在** + 举证范围 + 举证日期。

## 判定体系

| 判定 | 含义 |
|---|---|
| **可做** | 三门禁全过，可直接进入阶段 3 |
| **有条件可做** | 三门禁通过但有明确阻断项，须先落实阻断项 |
| **待核实后可做** | 存在关键未知项，核实前不得申报 |
| **不可做** | 存在硬约束或已被占位，原样申报会翻车 |
| **不可救** | 不可做，且**改也救不回来**，应从候选池移除 |

## 三类失败原因

审查中反复出现的失败，可以归为三类，**改法完全不同**：

- **类型 ①：别人已经做了** —— 不是不能做研究，是不能这样立项。改法是换立论方式或换对象。
- **类型 ②：我们根本做不了** —— 预算、数据、专业背景的硬约束。改法只有降级或放弃。
- **类型 ③：工程集成，不是研究问题** —— 申报书上去了会被问「研究贡献是什么」。改法是并入别的主线。

## 与 E10 正式交付物的关系

`../E10/` 是**唯一已经完整立项**方向的正式交付物工作区
（含申报书、选题论证、预算表、技术方案等）。

`16-E10-养殖AI可信性工程/` 下的三份门禁文件是**交叉引用版**，
只保留判定结论与证据指针，目的是让 16 个方向在本工作区内横向可比。
**凡两者冲突，以 `../E10/` 为准。**

## 表述红线（全文适用）

1. 不编造文献、DOI、作者、期刊、数字、产品名、备案号。
2. 「我没检索到」≠「不存在」——禁止把检索范围当成事实边界。
3. 立项须走**能力差异型论证**，不得用「文献空白」立项。
4. 中文期刊（CNKI / 万方）覆盖不足必须如实声明。
5. 所有否定性结论必须给**举证范围与日期**。
