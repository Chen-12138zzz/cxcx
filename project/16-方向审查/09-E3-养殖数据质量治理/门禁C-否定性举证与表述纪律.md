## 2. 本方向特有的表述陷阱

E3 有一个**极其危险的表述陷阱，必须逐字避免**：

> ❌ **错误写法**：「养殖数据质量治理尚属空白，是一个被忽视的蓝海。」
>
> ✅ **正确写法**：「在所及范围内未见专门的养殖数据质量产品；
> **但这一现象更可能源于需求强度不足（该能力已被硬件层以低成本子模块形式消化），
> 而非技术空白。本项目据此把立论建立在研究缺口（缺可复现的养殖 benchmark 与物理先验 QC 语义）
> 而非市场缺口之上。**」

这一段话看起来在削弱自己，实际上是在**保护自己**：
如果不说，评审一旦指出「广为海洋已经做了」，整个立论就崩了；
如果说了，就把弱点转化成了「我们清楚自己的处境」的证据。

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 完全空白 / 尚属空白 / 蓝海 / 被忽视的市场 | 在所及范围内未见专门的养殖数据质量产品 |
| 国内首个 / 首创 | （删除） |
| 「脏养殖数据」benchmark 尚属空白 | 在所及范围内未见公开的养殖专用可复现 QC benchmark |
