## 摘要

**16 个方向中，3 个可做，1 个待核实后可做，12 个不可做
（其中 5 个可救、7 个不可救）。**

必须承认一个不舒服的结论：**没有任何方向能靠「没人做」立项。**
16 个方向中 11 个的「产品重复性」评分 ≤ 3 分。
这不是本轮审查的发现，而是上一轮失败复盘时就已经指向的事实，
本次只是把它逐方向坐实了。

真正能走通的路径，是承认本项目的**真实资源禀赋**——
**我们有算力与方法，没有塘口、没有硬件预算、没有现场准入**——
然后只做那些匹配这个禀赋的方向。

按这个标准筛完，剩下的是：**E10（输出可信）+ E3（输入可信）+ E8（零硬件数据源）**。

## 一、为什么要做这次审查

上一轮工作区的结论是「**主推 D1 + D5**」。

这个结论在本地竞品调研后**被推翻**：
D1（智能投喂与摄食感知）已被**同城学生团队**——
湛江科技学院「智擎虾塘」——**成套占位**：

- 遂溪 / 坡头 **7 家养殖户试点**
- 水下监测浮标（浑浊水体识别残饵）
- 残饵识别双模型投喂决策
- 投饵机低成本智能化改造
- 投喂误差 < 5%、饲料浪费降 15%+
- 已有发明专利与软著

在同城、同为大创场景、对方已有落地试点的情况下，
**D1 作为独立选题已经不可能立项**。

关键问题不是「D1 能不能做」，而是：**其余 15 个方向会不会同样翻车？**
凭印象保留是不负责任的。因此把同一套方法对全部 16 个方向跑了一遍。

## 二、方法

### 门禁 A · 近邻尽调（五级半径，不许跳级）

| 级别 | 半径 | 为什么在这一级 |
|---|---|---|
| 1 | **本校**（广东海洋大学） | 同学院团队占位最致命——评委就是他们 |
| 2 | **同城学生团队** | 大创场景下比大公司更致命：同赛道、同周期、同评委池 |
| 3 | **同城公司** | 上一轮漏过这一级，本轮补上 |
| 4 | 国内公司 / 高校 | |
| 5 | 国外 / 学术文献 | |

**经验修正**（已写入 README）：查「谁在做同一件事」的正确顺序是
**同校 → 同城学生团队 → 同城公司 → 国内公司 → 学术文献**。

本轮实际命中的关键占位者（均已核实）：

| 占位者 | 类型 | 覆盖方向 |
|---|---|---|
| **海创团队 / 海创智渔**（本校数计学院） | 本校 | D2、E1、E2、E4 |
| **智擎虾塘**（湛江科技学院） | 同城学生队 | **D1、E1、E5** |
| 杰丰物联 / 昆鹏科技（湛江） | 同城公司 | E1 |
| 人保财险「粤海保」（雷州流沙湾） | 同城公司 | D1、D3、E1 |
| 湛江湾实验室「湛江湾 1 号」 | 同城机构 | D1、D2、D5、D6 |
| **北冥智渔**（青岛励图高科） | 国内公司 | D1、**D4**、**D6** |
| **稷安智算**（西北农林） | 国内高校 | **E10**（对象不同） |

### 门禁 B · 能力差异检验（三问）

1. 我具备什么别人不具备的能力？
2. 具备该能力的人为什么没做？
   ——**答案必须是「动机不匹配」或「粒度不匹配」，不能是「他们没想到」**。
3. 不具备该能力的人做得了吗？

> 问 2 的答案限制是全部门禁中最重要的一条设计。
> 「他们没想到」意味着**只要有人想到就没了**——这不能作为立项依据。
> 只有**动机**与**粒度**这种结构性的不匹配，才是可持续的差异。

### 门禁 C · 否定性举证与表述纪律

**禁用**：均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 /
未检索到同类 / 国内首个 / 首创。

**替代**：「**在所及范围内未见**」。

**强制附带**：举证范围 + 举证日期 + 「**未见披露 ≠ 不存在**」。

## 三、判定结果

完整表格见 `判定汇总表.md`。此处只列结论。

### 可做（3 个）

| 方向 | 分数 | 关键理由 |
|---|---|---|
| **E10 养殖 AI 可信性工程** | 6.6 | 唯一把「没有塘口」从劣势变成前提的方向。有《蓝哨》遗留的可评测资产。**阻断项 B-1（评审方）未落实** |
| **E8 无人机与遥感工程应用** | 6.2 | 实现难度最低。政府遥感服务面向监管端，与农户端自助体检**对象不同** |
| **E3 养殖数据质量治理** | 6.0 | 门禁 A/B 通过。**必须诚实说明需求弱**，立论建在方法缺口而非市场缺口 |

### 待核实后可做（1 个）

| 方向 | 分数 | 三条阻断项 |
|---|---|---|
| **D4 水产病害智能诊断** | 4.7 | D4-1 叮咚渔医是否覆盖南美白对虾<br>D4-2 水产学院数据通道<br>D4-3 病害图像真实可用量 |

D4 是 16 个方向中**唯一没有同城学生团队占位**的少数方向之一，
且「渔病通」明确未覆盖南美白对虾，因此**最值得抢救**。

### 不可做（12 个）

按失败类型分三类。

#### 类型 ①：别人已经做了（6 个）

D1、E1、D3、D2、D6、E2

**这一类的共同特征**：不是「不能做研究」，而是**不能这样立项**。
原立项逻辑是「这件事没人做」，而这件事有人做，
所以立论垮了——**而不是方向本身没有研究价值**。

其中 **D3 的情况最严重**：它与上一轮失败项目《蓝哨》**同构**，
产品重复性评分 1 分（16 方向最低）。团队已经做砸过一次同一件事，
而本轮审查**找不到「这次为什么不一样」的理由**。
D3 是唯一被明确判定「**不建议原样申报**」的方向。

#### 类型 ②：我们根本做不了（4 个）

E5、E4、E7、E9

**这一类的共同特征**：硬约束（预算 / 数据 / 专业背景），不是努力能解决的。

- **E4**：网衣清洗机器人 49–260 万，巡检 ROV 3–8 万起，预算 1 万。
- **E7**：供应链数据在恒兴、国联、政府手里，无获取渠道。
- **E9**：入门水声通信机 ¥9,999（通信实验需两台，即全部预算），且无水声背景。
- **E5**：16 方向末位 1.9 分，门禁 B **三问全否**——唯一一个。

#### 类型 ③：工程集成，不是研究问题（3 个）

D5、E6、E2

**这一类的共同特征**：做出来是产品，说不清**研究贡献**。
申报书上去了评委必问「你的研究问题是什么」，答不上来。

D5（边缘智能与轻量化部署）与 E6（模型轻量化与边缘部署）
**讲的几乎是同一件事**（模型压缩、算子优化、端侧推理），
分成两个方向是评审表设计上的冗余。

### 不可救（7 个）

E5、D3、D6、E4、E7、E9 —— 加上 D3 共 7 个方向标记为 ✖（不可救）。

**判定不可救的标准**：改法 A（降级）/ B（并入）/ C（重组）
**都救不回来**——要么前提冲突（E5 是装备方向，而本项目不做硬件），
要么硬约束无解（E4/E7/E9），要么合规准入制无法绕开（D6），
要么找不到「这次为什么不一样」（D3）。

## 四、三个必须正视的发现

### 发现 1：11 个方向的「产品重复性」≤ 3 分

这是《全方向评分报告》的原始结论，本次审查逐方向坐实了。
含义：**任何以「工具缺失」「没人做」为立论的大创申报书，都会被问倒。**

### 发现 2：前三名中有两个的共同点是「不产生养殖数据」

E10（6.6）与 E3（6.0）都**不产生养殖数据，只处理数据**。

E8（6.2）稍特殊：它产生数据，但通过**遥感**产生——
不进塘口、不碰硬件、不需要现场准入。

**这三个方向共同暴露了本项目的真实资源禀赋**：
**有算力、有方法，没有塘口。**

而 E4/E7/E9/E5 的失败，恰恰都是因为它们需要塘口、设备或供应链数据。

> 这个发现的价值在于：它给出了**筛选新方向的可操作标准**——
> 一个候选方向如果要求「进塘口 / 买设备 / 拿企业数据」，
> 它在第一轮就该被淘汰，无需进入详细论证。

### 发现 3：8 个方向的「差异化卖点」最终都指向了「输出可信性」

D1、D2、D3、D5、D6、E2、E5、E9 —— 这 8 个方向在论证过程中，
其「与竞品的差异点」无一例外地收敛到了同一件事：

> 「别人的预警/检测/建议**不一定准**，我们的**能验证准确性**。」

而这正是 **E10 的内容**。

**这不是巧合。** 它说明这些方向**自身缺乏立论**，
只能借用 E10 的论点来包装自己。

**借用者是撑不起独立项目的**——因为一旦去掉这个借用的卖点，
它们就退化成了「别人已经做过的东西」。

这也从反面印证了 E10 的合理性：
**如果 8 个方向都需要「可信性」来给自己找差异，
说明「可信性」在这个领域是一个真实且普遍未被满足的需求。**

## 五、与上一轮《蓝哨》三条教训的呼应

| 《蓝哨》失败原因 | 本轮对应发现 | 处置 |
|---|---|---|
| **用「没人做」立项** | 16 方向中 11 个重复性 ≤3 分；D1/E1/D3/D2/D6/E2 六方向直接因占位出局 | 全方向改走能力差异型论证 |
| **约束伪装成创新** | 「我们没条件做 A 所以做 B」被逐条识别 | E4/E7/E9 不再包装，直接判「做不了」 |
| **内容错置** | 8 个方向借用 E10 的「可信性」卖点 | 逐条剥离，还原各方向自身的真实内容 |

**最重要的教训转化**：

上一轮的失败根因是「机制成立但撑不起项目」。
本轮审查把这一点变成了**门禁 B 的问 2 限制**——
「他们没想到」不能作为理由，必须是「动机/粒度不匹配」。

理由是：
- 「他们没想到」是**偶然的**，随时可能被消除 → 撑不起项目。
- 「动机/粒度不匹配」是**结构性的**，不随某人想到而消失 → 能撑起项目。

**而这也正是 E10 的阻断项 B-1 为什么必须落实**：
只有找到真实的**评审方**，才能证明「动机不匹配」这个论证成立。
没有评审方，E10 会重演《蓝哨》的失败模式。
