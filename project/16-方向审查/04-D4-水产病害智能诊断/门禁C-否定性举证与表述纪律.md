## 2. 本方向特有的表述陷阱

D4 最容易出现的违规表述是 **「对虾病害诊断是空白」**——
但叮咚渔医已含虾病模块，SHRIMPAI 已做 WSSV。这类表述一旦写出，会被一票否决。

另一类陷阱是把 **「叮咚渔医的专家网络含广东海洋大学」** 解读为「我们有优势」。
**恰恰相反**：这说明对方已经接入了本校的专家资源，我方反而处于劣势或需寻求合作。

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 对虾病害诊断是空白 | 在所及范围内未见专门面向湛江对虾的轻量视觉诊断产品 |
| 我们有水产专家网络 | 删除——**对方有，我方没有** |
| 国内首个 / 首创 | （删除） |
