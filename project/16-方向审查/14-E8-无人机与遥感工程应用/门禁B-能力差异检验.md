# E8 · 门禁 B：能力差异检验

> 审查日期：2026-09-20 ｜ 前置：门禁 A（**已通过**）

---

## 1. 三问自检

### 问一：我具备什么别人不具备的能力？

| 候选能力 | 是否成立 | 依据 |
|---|---|---|
| 有免费遥感数据处理能力 | **成立，但可复制** | GEE / Copernicus 是公开工具；**任何人能学** |
| **有「零硬件、不入户」的数据获取路径** | **成立** | 这是 E8 最核心的能力——**覆盖没有传感器的养殖户** |
| 有本地化指标设计能力 | **成立** | 绑定湛江养殖周期与台风/赤潮窗口做时序对比 |
| 有可信性工程资产 | **成立** | 与 E10 同源（方法全开源可审计） |

**问一结论**：E8 的核心能力是 **「在不接触塘口、不装传感器、不花钱买数据的前提下，
产出对养殖户有意义的时序分析」**。这个能力确实稀缺——因为它要求**放弃硬件依赖**。

### 问二：为什么具备这些能力的人没做？

| 能力的持有者 | 为什么没做 |
|---|---|
| 政府遥感服务商（南海发展研究院、中绘云图） | 它们的合同对象是**政府**，交付物是监管图斑与专题图；**做农户端不赚钱也不在合同范围内** |
| 商业公司 | 遥感数据免费，**无法靠数据收费**；面向单个散户的边际成本高、客单价低 |
| 本校海创团队 | 技术栈在**传感器实时数据**，不做遥感时序回溯；**互补不冲突** |
| 学生团队（智擎虾塘等） | 做的是塘内硬件与投喂，不涉及天上遥感 |

**关键判断**：这一问的答案是**「商业模式不匹配 + 对象不同」**，
属于**真实且不会自动消失的粒度错配**——政府服务商的合同结构决定了它们不服务散户。

**⚠️ 但必须承认脆弱点**：遥感数据免费意味着**技术门槛低**。
任何人（包括智擎虾塘）都可以扩展做遥感。**E8 的优势窗口依赖于「别人没意识到」，
这不如 E10 的「别人没动机」稳固。**

### 问三：不具备这些能力的人做得了吗？

**做得了技术，但做不了「农户能看懂的本地化」**：
1. 需要知道湛江的养殖周期与关键窗口（投苗、台风季、赤潮期）；
2. 需要把遥感的**光谱指标**翻译成**养殖决策语言**（「这口塘的浊度变化意味着什么」）；
3. 需要处理**大气校正**等专业环节的误差**并如实给误差区间**。

**第 3 条是 E8 最大的技术风险**，必须写进申报书的风险与应对。

## 3. 门禁 B 结论

| 项 | 结论 |
|---|---|
| 三问是否都能正面回答 | **是**（问一有真实候选；问二为对象与商业模式错配；问三给出具体门槛） |
| 是否存在阻断项 | **是，三条**，其中 B-1 决定立论成败 |
| **门禁 B 判定** | **通过（条件性）** |
| 完成日期 | 2026-09-20 |

**与 E10 的对比**：
- E8 的门禁 B **较易通过**，但优势窗口**不如 E10 稳固**（技术门槛低，别人可复制）；
- E8 的最大优势是**可实现性最高（9 分）**，是「保底能交付」的那一支；
- **结论：E8 适合作为主选题或 E10 的并列支撑**，尤其适合与 E10 组合
  （E8 提供「零硬件数据来源」，E10 提供「输出可信层」）。
