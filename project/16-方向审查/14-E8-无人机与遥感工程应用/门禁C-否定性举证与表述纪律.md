## 2. 本方向特有的表述陷阱

E8 有三个陷阱：

**陷阱一：把「政府已有服务」说成空白。**
政府遥感服务是**已核实存在**的（广东 359.5 万、福建 29.1 万等服务）。任何「遥感监测是空白」的表述都会被击穿。

**陷阱二：把「农户端」的区分当作免费通行证。**
「对象不同」这个论证**必须被具体化**：农户要的不是「面积图斑」，
而是「我那口塘的水色/浊度最近怎么变了、台风前该做什么」。
**说不出具体差异，这个论证就是空的。**

**陷阱三：回避大气校正误差。**
竞品表原文已经点出：「学生做水质/赤潮反演时，大气校正等专业环节难保证可信度」。
**必须主动披露这一局限，而不是掩盖。**

| 禁用 | 替代 |
|---|---|
| 均为 / 仅见 / 没有人 / 无人研究 | 在所及范围内未见 |
| 遥感养殖监测尚属空白 | 改为：政府遥感服务面向监管端；**在所及范围内未见面向散户塘口自助分析的产品** |
| 高精度反演 | 改为：给出误差区间并说明校正方法的局限 |
| 国内首个养殖遥感自助平台 | （删除） |
