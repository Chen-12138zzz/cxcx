## 一句话结论

16 个方向中 **3 个可做**（E10 输出可信 / E3 输入可信 / E8 零硬件数据源）、
**1 个待核实后可做**（D4）、**12 个不可做**（5 个可救、7 个不可救）。

**没有任何方向能靠「没人做」立项**——16 个方向中 11 个的「产品重复性」≤ 3 分。

## 表述红线

1. 不编造文献、DOI、作者、期刊、数字、产品名、备案号。
2. 「我没检索到」≠「不存在」——禁止把检索范围当成事实边界。
3. 立项须走**能力差异型论证**，不得用「文献空白」立项。
4. 中文期刊（CNKI / 万方）覆盖不足必须如实声明。
5. 所有否定性结论必须给**举证范围与日期**，并附「**未见披露 ≠ 不存在**」。
