## 2. 软件功能说明

### 2.1 开发目的

针对 GIS-MCE（地理信息系统-多准则评价）养殖适宜性评估领域存在的两个问题：

1. **报告缺失导致不可复现**：71 篇文献中 **49 篇未报告空间分辨率**、
   13 篇未报权重赋值、24 篇未报重分类分值
   （Silverthorn 等，2025，*PLOS Sustain. Transform.* 4(1):e0000155）；
2. **输出分辨率与决策单元不匹配**：主流研究面向海湾/河口级（栅格 30 m–1 km），
   而高位池单池尺度约 50 m。

本软件把上述"缺失"**转化为可计算的后果**，为研究者提供一套可复现的审计工具。

> ⚠️ **本软件不产出任何选址结论、选址图或管理建议。**
> 它审计的是"做选址评估这件事"，不是做出选址评估。

### 2.2 主要功能模块

| 模块 | 文件 | 功能 |
|---|---|---|
| **合成数据模块** | `src/synth.py` | 生成三层可分辨的合成适宜性场（真值已知）；生成高位池规则布局；块平均粗化 |
| **评价引擎模块** | `src/mce.py` | min-max 与模糊隶属度重分类；加权线性组合（WLC）；AHP 判断矩阵；秩相关与前 k% 重叠率 |
| **尺度失配诊断模块** | `src/fusion/scale.py` | 输出网格粗于决策单元时的代价量化；纯几何诊断 |
| **融合账本模块** | `src/fusion/gain.py` | 误差三分解（偏差/方差/MSE）；仿射标定分离结构误差与尺度误差；权重扰动实验 |
| **审计模块** | `src/audit/audit.py` | 把报告缺失转化为可计算后果；退化自检 |
| **自动化测试** | `tests/run_tests.py` | 140 条不变量断言 |
| **实验脚本** | `experiments/exp0~3_*.py`、`run_all.py` | 4 个实验共 31 条判据；一键复现 |

### 2.3 技术特点

| 特点 | 说明 |
|---|---|
| **零外部依赖（除 numpy）** | 秩相关、AHP 特征向量、块平均全部用显式线性代数重实现，便于逐步独立核对 |
| **可完全离线运行** | 无网络请求；无地理数据依赖 |
| **确定性可复现** | 全部随机性由显式种子控制，同种子**逐位相同** |
| **退化输入显式报错** | 常数层、未归一化权重、真值零方差、含 NaN 输入等一律报错，不静默产出"看起来正常"的结果 |
| **不预设结论方向** | 融合账本保留 `fusion_helps` / `fusion_hurts` / `inconclusive` 三种判定，由数据决定 |
| **测试与实现同等地位** | 140 条断言把每一项"声称的性质"变成可执行断言 |

### 2.4 运行环境

| 项 | 要求 |
|---|---|
| Python | 3.10 及以上（实测 3.13.12） |
| 第三方库 | **仅 numpy**（实测 2.5.3） |
| 内存 | 建议 ≥ 2 GB（128×128 场域峰值占用很小） |

### 2.5 运行方式

```bash

# 单独运行某一实验
python experiments/exp1_scale.py

# 单独运行单元测试
python tests/run_tests.py
```

## 4. 真实性声明

1. 本软件为**原创实现**。所使用的数学方法（WLC、AHP、模糊隶属度重分类、
   Spearman 秩相关）均为公开的既有方法，**本软件不声称在这些方法上有创新**；
   创新在于把这些方法转化为**可分解、可扰动、可审计**的部件。
2. 本软件**不含任何通过不正当手段获取的代码或数据**。
3. 本软件**不包含**任何真实地理坐标数据；其合成场由算法生成，
   **不对应任何真实地点**。
4. 本软件所引用的文献均已核验，核验状态标注于
   `01-调研/03-参考文献清单.md`。
