## 1. 合成真值场的构造

### 1.1 目标

构造一个**结构已知**（三个可分辨尺度）的空间场，作为全部精度/误差数字的真值来源。

**为什么不能是纯噪声**：若合成场只是随机噪声，则"融合是否提升精度"毫无意义 ——
任何方法都能在噪声上表现"更好"或"更差"。因此必须有**可分辨的多尺度结构**。

### 1.2 算法：谱域高斯低通

对第 `i` 个结构层（特征长度 `L_i`，振幅权重 `w_i`）：

```
white_i  ~ N(0, 1)                          # 独立白噪声，形状 (n, n)
F_i      = FFT2(white_i)
K        = sqrt(kx² + ky²),  k = fftfreq(n, d = cell_m)    # 周期/米
filt_i   = exp( −(K · L_i)² / 2 )            # 高斯低通
low_i    = Re( IFFT2(F_i · filt_i) )
low_i    = (low_i − mean(low_i)) / std(low_i)   # 去均值、归一化标准差
layer_i  = w_i · low_i

raw      = Σ_i layer_i
```

**关键设计**：

| 决策 | 理由 |
|---|---|
| 谱域高斯低通（而非空域卷积） | 无边界效应问题；且 `filt` 的形状直接对应"特征长度"的物理含义 |
| 每层**先归一化到单位标准差**再乘 `w_i` | 使各层振幅可控、可解释（`w_i` 就是各层的相对振幅） |
| 三层各用**独立** `white_i` | 若共用同一白噪声，各层将完全相关，就无法"逐层分离" |

**⚠️ 一个必须记录的后果**：三层由**独立**白噪声经**不同**低通得到，
因此它们**互不独立**（低通使频谱重叠）⇒ 层间协方差非零
（实测 `cov(L1,L2) = −0.0339`）⇒ **方差不可加**，必须含交叉项：

```
var(raw) = Σ var(layer_i) + 2 · Σ_{i<j} cov(layer_i, layer_j)
         = 1.482500 + (−0.060073) = 1.422427     ✓ 实测闭合误差 0.000e+00
```

> 这条是 `修正记录.md` **B-1** 的来源。把方差可加当作无条件恒等式，
> 会得到一个**假警报**。

### 1.3 标准化与 `sd` 的保留

```
sd      = std(raw)
truth   = (raw − mean(raw)) / sd          # 若 standardize=True
```

**必须同时返回 `sd` 与 `mean_raw`**，使下式成为**可断言**的恒等式：

```
truth · sd + mean_raw == raw
```

`tests` A5 实测 `max|err| = 4.441e-16`。

> **来源**：F1 方向 R-2。结果若被标准化而真值不换算到同一尺度，
> 会出现"不随样本量消失的常数偏倚" —— 一个**伪装成方法缺陷**的尺度错误。

### 1.4 三层可分辨性的验证（前置判据）

| 层 | 标称特征长度 | 100 m 块平均后保留方差 | 径向能谱峰值波长 |
|---|---|---|---|
| L1 | 800 m | 0.9390 | 943 m |
| L2 | 200 m | — | 404 m |
| L3 | 50 m | **0.0967** | 69 m |

**判据**：L3 保留 < 15%（实测 0.0967 ✓）、L1 保留 > 85%（实测 0.9390 ✓）、
L3/L1 < 0.25（实测 0.1029 ✓）、峰位随标称尺度严格递减（943 > 404 > 69 ✓）。

> **⚠️ 峰位低于标称尺度是高斯低通的固有性质**（截至尺度以下的能量按幂律累积）。
> 因此"三层可分辨"的**正确可检验命题是"峰位单调"**，
> 不是"95% 能量在 800 m 以上"（实测仅 27.09%）—— 见 `修正记录.md` **B-2**。

## 2. 粗化算子（尺度失配的实现基础）

### 2.1 块平均

对 `n × n` 场按 `factor × factor` 分块取均值：

```python
m = n // factor
coarse = field.reshape(m, factor, m, factor).mean(axis=(1, 3))
```

**性质**：保均值（`tests` A12 实测 2047.5 == 2047.5）。

**为什么只提供块平均**：抽点采样 `field[::factor, ::factor]` 会引入**混叠**，
且不是融合的平均语义。本诊断要测的是**块平均带来的尺度失配**，
不是采样策略的差异。若需对比，必须**显式命名** `point_sample` 并单独说明。

**⚠️ 限制**：只支持**整数倍**粗化 ⇒ **可测尺度是离散的**。

### 2.2 两种聚合口径

| 口径 | 定义 | 语义 |
|---|---|---|
| `all_mean` | 块内全部像元平均 | "这一片**区域**的适宜性" |
| `pond_mean` | 仅在 `mask=True` 像元上平均 | "这一片**池**的平均适宜性" |

`pond_mean` 下若某粗格内**无任何**有效像元，结果为 `NaN`：

```python
out = np.full((m, m), np.nan); ok = den > 0; out[ok] = num[ok] / den[ok]
```

**为什么不填 0**：填 0 会让下游把**"无数据"**当成**"最不适宜"** ——
一个静默且**方向性**的错误（`tests` C2–C4）。

**两口径的分离量级**（实测，标准化真值量纲）：

| factor | 格内池体占比 | \|pond_mean − all_mean\| 均值 | 最大 |
|---|---|---|---|
| 2 | 4.000 | 0.0000 | 0.0000 |
| 4 | 15.413 | 0.0137 | 0.4993 |
| 8 | 57.327 | 0.0482 | **0.8691** |

⇒ 池体占比中等时两口径显著分离。**论文不写明口径，读者无法复现结论。**

## 3. 评价引擎

### 3.1 线性 min-max 重分类

```
若 invert=False：  s = (x − min x) / (max x − min x)
若 invert=True：   s = 1 − 上式                    # 成本型图层
```

**⚠️ 常数层（`max x = min x`）会静默得到全 0。** 这是**刻意**选择：

> **静默失效最危险。** 宁可让调用方看到"全 0"然后被迫处置，
> 也不要掩盖。配套的 `assert_not_degenerate` 负责**显式报错**。

### 3.2 模糊隶属度重分类

```
edge='both'： s = clip( (x − lo) / (hi − lo), 0, 1 )
```

与 min-max 的**本质区别**：

| | 依据 | 后果 |
|---|---|---|
| `minmax` | **数据极值** | 受异常值影响；隐含"该层内必然有最适宜与最不适宜" |
| `fuzzy` | **物理解释边界** `lo/hi` | 需要领域知识；可表达"超过阈值即饱和" |

⇒ 两者的差异正是 Q3 要审计的"重分类选择"问题之一。

### 3.3 加权线性组合（WLC）

```
score = Σ_k w_k · s_k          s_k ∈ [0,1]
约束：w_k ≥ 0 且 Σ_k w_k = 1
```

**为什么强制 `Σw = 1`**：不归一化会使 `score` 的**量纲随权重漂移**，
于是"精度"与"权重"两个因素**纠缠**，无法分离。
因此**报错而不静默缩放**（`tests` B12）。

**⚠️ 一个必须知道的性质（本项目主结果的机理）**：

`Σw = 1` 的 WLC 是各层的**凸组合**。若各层近似独立同方差 `σ²`，则

```
Var(score) = Σ_k w_k² σ²  ≤  σ²        （Schwarz 不等式，等号仅当某 w_k = 1）
```

⇒ **融合会压缩得分场的方差。** 实测（合成场，`w = [0.5128, 0.3077, 0.1795]`）：

| 量 | 值 | 相对 |
|---|---|---|
| var(truth) | 1.0221 | — |
| var(single_L1) | **0.0265** | 真值的 **0.0259×** |
| var(fused_L1L2L3) | 0.0092 | 单层的 0.3479× |
| 凸组合理论上界 `Σw²` | 0.3899 | — |

⇒ **得分是单调代理，不是同尺度估计。** 这一条直接决定了误差分解必须"标定后"再看
（见 §4.2）。

### 3.4 AHP（**反向**使用）

**标准流程**：专家填判断矩阵 → 求主特征向量 → 一致性比 CR。

**本项目做法**：给定优先级向量 `p`，构造**完全一致**判断矩阵

```
A_ij = p_i / p_j          ⇒  λ_max = K，CI = 0，CR = 0
```

然后回算特征向量验证能复原 `p`（`tests` B19 实测复原 `[0.2, 0.3, 0.5]`）。

**为什么反向**：本项目**无专家、无现场**，**不得编造专家判断**。
此函数只用于**验证权重扰动实验的载体正确性**，**不用于声称任何"专家权重"**。

**⚠️ 顺带澄清 AHP 判断矩阵的性质**：

| 性质 | 式子 | 是否成立 |
|---|---|---|
| 互反 | `A_ij · A_ji = 1` | ✅ 成立（`tests` B21 实测误差 0） |
| 对角线为 1 | `A_ii = 1` | ✅ 成立 |
| **对称** | `A_ij = A_ji` | ❌ **一般不成立**（`tests` B21b 实测 `max\|A−Aᵀ\| = 2.10`） |

> 因为 `0.5/0.2 = 2.5` 而 `0.2/0.5 = 0.4` —— 互为倒数，绝不相等。
> 把"互反"误写成"对称"曾导致一条错误的测试断言（`修正记录.md` C-1）。

### 3.5 秩相关与前 k 重叠

**Spearman ρ**（显式实现，无 scipy 依赖）：

```
r = rankdata(a) − mean(rankdata(a))
s = rankdata(b) − mean(rankdata(b))
ρ = (r · s) / sqrt( (r²)·(s²) )            # 恒在 [−1, 1]
```

`rankdata` 用**平均秩**处理并列（与 scipy `'average'` 一致）。
`tests` B27 校验 `[10,20,20,30] → [1, 2.5, 2.5, 4]`；
B26 断言**并列时 ρ 不虚高**（实测 0.333）。

**前 k 重叠率**：

```
k = max(1, round(n_ranked · k_frac))
overlap = |{前 k 名 by A} ∩ {前 k 名 by B}| / k
```

**为什么需要它（而不只有 ρ）**：决策者关心的是"**我要看的那几块地变没变**"，
不是全部地块的秩是否一致。

> **本项目实测到的一个重要事实**：在重分类互换实验中，
> ρ = 0.9095（看起来"还不错"），而前 10% 重叠率仅 **0.5649**
> —— **近一半的推荐地块换了**。
> ⇒ **秩相关不反映前端的置换强度。** 两个指标必须同时报。

## 4. 误差分解（本项目最关键的一个设计）

### 4.1 三个必须分开的量

设预测 `p`、真值 `t`（在同一组像元上）：

```
bias² = ( mean(p − t) )²                    # 系统偏离
var   = Var(p − t)                          # 围绕趋势的抖动
mse   = mean( (p − t)² )
```

**恒等式**（`tests`/exp2 G1 实测 `max|diff| = 2.220e-16`）：

```
mse_raw = bias² + var
```

**为什么必须分开**：

| 情形 | MSE | bias | var | 处置 |
|---|---|---|---|---|
| A | 大 | **小** | 大 | 纯方差问题 ⇒ 需要更好的数据 |
| B | 大 | **大** | 小 | 纯系统性偏移 ⇒ **一个常数即可修正** |

只看 MSE 会把这两类**完全不同**的问题混为一谈，导致"该修哪个"无从判断。

### 4.2 仿射标定（把"结构误差"与"尺度误差"分开）

允许用真值做**一次**仿射标定 `t ≈ a + b·p`（一元最小二乘）：

```
b = Σ(p − p̄)(t − t̄) / Σ(p − p̄)²
a = t̄ − b·p̄
mse_calibrated = mean( residual² )
share_of_error_from_scale = 1 − mse_calibrated / mse_raw
```

**判读**：

| 若 | 说明 |
|---|---|
| `mse_calibrated ≪ mse_raw` | 误差主要是**尺度/偏移**问题（可被一次标定消除） |
| `mse_calibrated ≈ mse_raw` | 误差是**结构化**的（标定救不了） |

**两个必须记住的标定值**（`tests`/exp2 实测）：

| 情形 | `share_of_error_from_scale` | 含义 |
|---|---|---|
| `p = 2t`（纯缩放） | **1.000000** | 标定后 MSE 归 **0** |
| `p ⟂ t`（纯随机） | **≈ 0.5** | 标定后 MSE 仍为 `Var(t)`；**0.5 是"救不了"的上界，不是 0** |

> ⚠️ 纯随机情形下 `share → 0.5` 而非 0：因为 `b→0` 时残差即真值自身波动，
> `MSE_cal → Var(t)`，而 `MSE_raw → 2·Var(t)`，故 `share → 1 − 1/2 = 0.5`。
> 实测 60 个种子 `mean = 0.5001, sd = 0.0104`。
> 把它误当"应该接近 0"会写出错误的判据（`修正记录.md` C-3）。

### 4.3 ★ 本设计揭示的核心现象：符号反转

**实测（合成场，池体像元 11236，`w = [0.5128, 0.3077, 0.1795]`）**：

| 方案 | NMSE_raw | pearson_r | NMSE_cal | calib_b |
|---|---|---|---|---|
| `single_L1` | **1.0736** | 0.8155 | 0.3349 | 5.07 |
| `fused_L1L2` | 1.1106 | 0.9546 | 0.0887 | 8.48 |
| `fused_L1L2L3` | **1.1224** | **0.9961** | **0.0077** | 10.49 |

融入更细的源（A→C）：

```
Δnmse_raw        = +0.0488    （变差！）
Δpearson_r       = +0.1806    （大幅变好）
Δnmse_calibrated = −0.3271    （大幅变好）
```

⇒ **一个孤立的精度数字可以把结论的符号搞反。**

**机理**：`calib_b` 逐级放大（5.07 → 8.48 → 10.49），
说明得分被**仿射压缩**（§3.3 的凸组合压缩 + min-max 的 [0,1] 压缩）。
被压缩的成分占原始 MSE 的绝大部分，而它是**一次标定即可移除**的。

> **这条是本项目最有力的示范，也是 `修正记录.md` B-5 的来源。**
> 当时"判据失败"的处置**不是改判据让它通过**，而是
> **把这次失败变成项目的主结果**（新增 G4b 断言"符号反转确实存在"）。

### 4.4 融合账本

```
输入：{方案名: 得分场}，真值，mask，基线名
输出：per_scheme（逐方案误差分解）、gain_vs_baseline（相对基线增益）、verdict
```

**增益的正负约定**：`nmse_reduction > 0` 表示**优于**基线。

**判定规则（不预设方向，红线 G-3）**：

```
只看键名以 'fused' 开头的方案相对基线的 NMSE 变化：
  全部为正  → fusion_helps
  全部为负  → fusion_hurts
  符号混杂  → inconclusive
若无融合方案 → inconclusive（不臆断）
```

`tests` D19 专门断言"**融合更差时必须如实报 `fusion_hurts`**"（实测通过）。

### 4.5 权重扰动

**扰动模型**：对数正态扰动再归一化（保证权重恒正、和为 1）：

```
w'_k ∝ w_k · exp( N(0, rel_sd²) )
w'  = w' / Σ w'
```

**为什么用对数正态**：WLC 要求 `w_k ≥ 0` 且 `Σw = 1`。
普通正态扰动会产生负值并破坏归一化，对数正态天然满足两条约束。

**`rel_sd` 的含义**：约等于"权重可有 `rel_sd × 100%` 的相对不确定"。
**⚠️ 这是示范性设定，不是实测的专家分歧度**（红线 G-5）。

**曲线的必含档**：`rel_sd = 0`。

> **恒等自检**：若 `rel_sd = 0` 时前 k 保留率不是 1.0，实现有问题。
> 若它**恒为 1**（任何 `rel_sd` 都是 1），说明扰动没生效。
> ⇒ **"恒不通过"和"恒通过"都是可疑信号**（F1 方向 R-13 教训）。
> `tests` D25–D27b 断言是"**逐次**为 1"而非"平均为 1"（实测 min = max = 1.000000000000）。

**输出字段（语义无歧义）**：

| 字段 | 含义 | `rel_sd = 0` 时的值 |
|---|---|---|
| `topk_kept_share` | 前 k% **保持率** | 1.0 |
| `topk_kept_count` | 前 k 名里**留住**的个数 | k |
| `topk_changed_count` | 前 k 名里**换掉**的个数 | **0** |

**恒等式**：`topk_kept_count + topk_changed_count == k`（逐次抽样成立，`tests` D27b）。

> 曾因字段语义歧义出过缺陷（`修正记录.md` A-3）。

## 5. 审计模块

### 5.1 三条缺失 → 三个后果的映射

| 缺失项 | 原统计 | 对应后果 | 计算方式 |
|---|---|---|---|
| 空间分辨率 | 49/71 | 决策/信息损失比 | `scale_mismatch_curve` |
| 权重赋值 | 13/71 | 前 k% 换掉几个 | `weight_perturbation_curve` |
| 重分类分值 | 24/71 | 前 k% 换掉几个 | `reclass_choice_sensitivity` |
| 数据来源/年份 | 10/71 + 28/71 | **不产数** | `timeliness_flags`（清单） |

**实测后果**（池体像元 11236，`k = 1124`）：

| 缺失项 | 后果 |
|---|---|
| 分辨率 | 比值最高 **2.28×**（50 m 处） |
| 权重 | `rel_sd=0.30` 时换掉 **131.5 / 1124**（11.7%） |
| 重分类 | 换掉 **489.0 / 1124**（**43.5%**） |

> **★ 一个值得注意的对比**：重分类（43.5%）的后果**远大于**权重扰动（11.7%），
> 而原文献里"未报重分类"（24/71）也只比"未报权重"（13/71）多约 1.85 倍，
> 后果却是约 3.7 倍 ⇒ **两者非线性**。

### 5.2 重分类方案敏感性

```
对每种重分类方案 sch ∈ {minmax, fuzzy}：
    rel_k = 重分类(层 k, sch)
    score_sch = WLC(rel, w)
两两比较：Spearman(score_A, score_B) 与前 k 重叠率
```

**实现细节**：`lo/hi` 由**调用方给出**，本项目在示范运行时取合成层的 25%/75% 分位数
并**显式标注**（不自行编造领域阈值）。

### 5.3 退化自检

`audit_summary` 内置：

```
若 rel_sds 含 0：
    检查 topk_kept_share_mean == 1.0（容差 1e-9）
    否则 degeneracy_check.ok = False
若 rel_sds 不含 0：
    degeneracy_check.ok = False，note = "未提供 rel_sd=0 基线，无法验证实现正确性"
```

`tests` E13 断言"**缺基线时必须报 False**" —— 这是一个**恒不通过自检**：
如果它永远报 True，那这个自检本身就没有价值。

## 6. 算法复杂度

| 函数 | 时间 | 空间 | 说明 |
|---|---|---|---|
| `make_multiscale_field` | `O(L · n² log n)` | `O(n²)` | `L` = 层数，FFT 主导 |
| `block_average` | `O(n²)` | `O(n²)` | 一次 reshape + mean |
| `aggregate_to_coarse` | `O(n²)` | `O(n²)` | 同上（`pond_mean` 多一次加权求和） |
| `wlc_score` | `O(K · n²)` | `O(K · n²)` | `K` = 层数，张量收缩 |
| `spearman_rho` | `O(N log N)` | `O(N)` | 排序主导 |
| `scale_mismatch_curve` | `O(F · n²)` | `O(n²)` | `F` = factor 个数 |
| `weight_perturbation` | `O(D · K · n²)` | `O(n²)` | `D` = 抽样次数（默认 200） |
| `weight_perturbation_curve` | `O(S · D · K · n²)` | `O(n²)` | `S` = `rel_sd` 档数 |

与 exp3 的 6 × 200 次扰动抽样）在本机秒级完成。

## 7. 数值稳定性处理

| 风险 | 处置 | 位置 |
|---|---|---|
| 除以 0（极差为 0） | 显式判断后产全 0，配套 `assert_not_degenerate` 报错 | `minmax_normalize` |
| 除以 0（真值方差为 0） | **报错**（保留率无定义） | `scale_mismatch_curve` |
| 除以 0（粗格无有效像元） | 返回 `NaN`（**不填 0**） | `aggregate_to_coarse` |
| 秩相关分母为 0（至少一方常数） | 定义上返回 1.0（完全一致） | `spearman_rho` |
| 线性拟合斜率为 0（`x` 为常数） | **报错**（退化输入） | `_linear_fit` |
| 输入含非有限值 | **报错**，不静默跳过 | `error_decomposition` |
| 层间协方差被忽略 | **显式计算并报告**交叉项 | `exp0` P1/P1b |
