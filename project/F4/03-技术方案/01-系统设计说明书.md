## 1. 设计目标与不做的事

### 1.1 三个可回答的问题

| 编号 | 问题 | 为什么它值得单独成一个问题 |
|---|---|---|
| Q1 | 多源融合的**精度增益**与**方差代价**各是多少？ | "融合更好"若不指定基线就没有内容；且增益必须可分解，否则不知道"该修哪个" |
| Q2 | 输出网格**粗于决策单元**时，"精度"还站得住吗？ | 49/71 篇文献未报分辨率 ⇒ 读者无法判断结论作用于多大地块 |
| Q3 | "报告缺失"到底造成多大**后果**？ | 把"缺失计数"变成"可计算后果"是既有文献**未做**的一步 |

### 1.2 明确不做

| 不做 | 理由 |
|---|---|
| ❌ 不产出选址结论、选址图、管理建议 | 红线 **G-1**；且无现场数据，任何选址结论都无依据 |
| ❌ 不声称在 WLC/AHP 上有方法创新 | 它们是 2000 年以来该领域标准配方（Chentouf 2023 综述结论） |
| ❌ 不接收任何真实研究的内部参数 | 红线 **G-5**：避免用本项目输出指责任何具体已发表研究 |
| ❌ 不产生"实测准确率" | 无现场准入、无实测真值（约束 U-1） |

### 1.3 设计约束（决定了整个架构）

| 约束 | 对设计的影响 |
|---|---|
| **无实测数据** | 必须自建**结构已知**的合成场作为真值来源；随机性必须完全由种子控制 |
| **需要"权重变化 0.01 时排序变了几个"这一粒度** | 不能用 QGIS/rasterio/GDAL（这些步骤是黑箱）⇒ **必须用显式线性代数重实现** |
| **实现正确性须自证** | 因为是自己重实现的，所以每条性质都要有可执行断言 ⇒ `tests/` 与实现同等重要 |
| **不能静默失效** | 退化输入必须**报错**而非产出"看起来正常"的结果（如常数层被 min-max 静默变成全 0） |

## 2. 总体架构

```
                    ┌─────────────────────────────┐
                    │  synth.py  合成数据层        │
                    │  · 三层可分辨场（真值已知）   │
                    │  · 高位池规则布局             │
                    │  · 块平均（唯一合法粗化）      │
                    └──────────────┬──────────────┘
                                   │ truth / mask / layers
                    ┌──────────────▼──────────────┐
                    │  mce.py  评价引擎层           │
                    │  · minmax / fuzzy 重分类      │
                    │  · WLC（强制 Σw=1）           │
                    │  · AHP（互反矩阵，CR）        │
                    │  · 秩相关 / 前 k 重叠         │
                    └──────────────┬──────────────┘
                                   │ score fields
          ┌────────────────────────┼────────────────────────┐
          │                        │                        │
┌─────────▼─────────┐   ┌──────────▼──────────┐   ┌─────────▼─────────┐
│ fusion/scale.py   │   │  fusion/gain.py     │   │  audit/audit.py   │
│ 尺度失配诊断       │   │  融合账本 + 误差分解 │   │  缺失→可计算后果   │
│ (Q2)              │   │  (Q1)               │   │  (Q3)             │
└───────────────────┘   └─────────────────────┘   └───────────────────┘
```

### 2.1 分层的理由

- **`synth` 独立成层**：真值来源必须与评价逻辑解耦，否则"用合成场验证合成场"。
- **`mce` 独立成层**：它是三个诊断共用的**唯一**打分入口。
  若 `scale` 与 `gain` 各自实现一遍 WLC，两者的"权重"语义会漂移，
  导致跨模块比较失去意义（`tests` F1 断言两模块的网格尺度一致，正是防这个）。
- **`fusion` 与 `audit` 并列**：`audit` 不调用 `scale`，而是**接收** `scale_curve`
  作为参数 —— 避免审计模块被尺度实现绑定。

### 2.2 依赖方向（严格单向）

```
synth ← mce ← fusion ← audit
```

**没有反向依赖**。`audit` 通过参数接收尺度结果（`scale_curve`）而非 import，
因此 `scale` 的改动不会波及 `audit`。

### 2.3 为什么 `fusion` 内部还分 `scale` 与 `gain`

两者的**评价对象不同**：

| 模块 | 变化的量 | 固定住什么 |
|---|---|---|
| `scale.py` | **空间support**（粗化倍数） | 权重固定、真值直接聚合 ⇒ 纯尺度效应 |
| `gain.py` | **源的组合与权重** | support 固定（都在池体像元上比较） ⇒ 纯组合效应 |

⇒ 这就是"**逐项分离**"纪律在架构上的体现：**一个模块只准单独动一个因素。**

## 3. 模块设计

### 3.1 `synth.py` — 合成数据层

**职责**：提供真值已知、结构可控的空间场，以及几何一致的池体布局。

| 函数 | 作用 | 关键设计决策 |
|---|---|---|
| `make_multiscale_field` | 生成三层可分辨场 | 用**谱域高斯低通**（`filt = exp(−(K·L)²/2)`），三层各由独立白噪声生成 |
| `make_pond_layout` | 规则高位池布局 | 单池 50 m + 道路 10 m，返回 `pond_id`（−1 = 塘埂） |
| `block_average` | **唯一合法**的粗化方式 | 刻意**不提供** `field[::factor]` 抽点路径 —— 那会引入混叠 |
| `target_factor_for_cell` / `effective_cell_m` | 尺度换算 | 供实验脚本把"目标米数"换成整数 factor |

**★ 关键设计：为什么必须保留 `sd`**

`make_multiscale_field` 返回 `sd`（标准化前的标准差）与 `mean_raw`。
这不是冗余字段 —— 它使 `truth * sd + mean_raw == raw` 成为**可断言**的恒等式
（`tests` A5，实测 `max|err| = 4.441e-16`）。

> 这条来自 **F1 方向 R-2 的教训**：结果若被标准化，真值必须同时换算到同一尺度，
> 否则会出现"不随样本量消失的常数偏倚"这类**伪装成方法缺陷**的尺度错误。

**★ 关键设计：为什么 `block_average` 不提供抽点采样**

抽点采样会引入混叠，且不是融合的平均语义。
本诊断要测的是**块平均带来的尺度失配**，不是采样策略的差异。
若将来确需对比，必须**显式命名**为 `point_sample` 并单独说明。

### 3.2 `mce.py` — 评价引擎层

**职责**：重分类、加权线性组合、AHP、排序与秩相关。**唯一**打分入口。

| 函数 | 作用 | 关键设计决策 |
|---|---|---|
| `minmax_normalize` | 线性 min-max 到 [0,1] | **不在内部**保护常数层 ⇒ 静默产全 0，由调用方处置 |
| `assert_not_degenerate` | 拒绝常数层 | 把退化情形**显式暴露**，不静默 |
| `reclass_fuzzy` | 模糊隶属度重分类 | 用**给定的物理解释边界** `lo/hi`，而非数据极值 |
| `wlc_score` | 加权线性组合 | **强制 `Σw=1`**，否则报错 |
| `normalized_weights` | 归一化 | 拒绝负值与全 0 |
| `ahp_priority_from_consistent` | 从已知权重反构判断矩阵 | **反向使用 AHP**（见下） |
| `rank_descending` / `spearman_rho` / `top_k_overlap` | 排序与一致性 | 平均秩处理并列，与 scipy `'average'` 一致 |

**★ 关键设计：为什么 WLC 强制 `Σw = 1`**

不归一化会让 `score` 的**量纲随权重漂移**，
使"精度"与"权重"两个因素**纠缠、无法分离**。
因此选择**报错而不静默缩放**（`tests` B12）。

**★ 关键设计：为什么 AHP 是"反向"用的**

AHP 标准流程是"专家填判断矩阵 → 求特征向量"。
本项目**无专家、无现场**（U-1/U-2），**不得编造专家判断**。
因此本函数**反过来**：给定一组权重，构造完全一致的判断矩阵
`A_ij = p_i/p_j`（一致性比必然为 0），
用途是**验证权重扰动实验的载体正确性**，**不用于声称任何"专家权重"**。

> ⚠️ 附带澄清（来自修正记录 C-1）：AHP 判断矩阵的性质是**互反** `A_ij = 1/A_ji`，
> **不是对称**。`tests` B21 断言互反、B21b 断言"一般不对称"。

**★ 关键设计：为什么秩相关自己实现**

无 scipy 依赖，便于审计。`_rankdata` 实现平均秩，
`tests` B27 用 `[10,20,20,30] → [1, 2.5, 2.5, 4]` 校验。
`tests` B26 断言"并列时 ρ 不虚高"（实测 0.333，若不做平均秩会虚高）。

### 3.3 `fusion/scale.py` — 尺度失配诊断（Q2）

**职责**：量化"输出 support 变粗"的代价，且**必须把两个不同性质的量分开**。

| 函数 | 作用 |
|---|---|
| `aggregate_to_coarse` | 粗化，支持 `all_mean` / `pond_mean` 两种口径 |
| `scale_mismatch_curve` | 主函数：逐 factor 输出三个量 |
| `pond_vs_grid_geometry` | **纯几何**诊断，不需任何数据 ⇒ 最稳 |
| `scale_mismatch_curve_perturbed` | 备用口径（含噪声），**不用于主结论** |

**★ 关键设计：三个量必须分开报**

| 量 | 定义 | 口径 |
|---|---|---|
| `variance_retention` | Var(粗格聚合值) / Var(真值在池体像元上) | **信息量** |
| `rank_agreement_cells` | ρ(粗格得分, 粗格基准) | 粗格间**决策** |
| `rank_agreement_pooled` + `topk_overlap_pooled` | 粗格展开回像元后的排名一致性 | 像元级**决策** |

**为什么不能合并**：一个方案可以"保留了 95% 的方差"却"把前 10 名换了 7 个"，
因为**小尺度结构的绝对方差占比可以很低，却恰好决定池与池之间的排序**。

**★ 关键设计：两个口径分开（防自比）**

`rank_agreement_cells` 的**得分**与**基准**必须来自**不同构造**：
基准 = `pond_mean`（只在池体像元上平均），得分 = `all_mean`（含塘埂）。
若两者都用同一口径，就是"自己跟自己比"，ρ 恒为 1（**修正记录 A-1**）。

**★ 关键设计：`pond_mean` 下无有效像元的粗格返回 `NaN`，不填 0**

填 0 会让下游把**"无数据"**当成**"最不适宜"** —— 一个静默且方向性的错误
（`tests` C2–C4）。

### 3.4 `fusion/gain.py` — 融合账本与误差分解（Q1）

**职责**：算清融合的账，且**不预设方向**。

| 函数 | 作用 |
|---|---|
| `error_decomposition` | 误差三分解 + 标定后误差 |
| `fusion_ledger` | 逐方案误差 + 相对基线增益 + 判定 |
| `weight_perturbation` | 权重扰动 → 排序翻转 |
| `weight_perturbation_curve` | 上者的曲线形式（**必含 `rel_sd=0`**） |

**★ 关键设计：误差三分解**

| 量 | 回答的问题 |
|---|---|
| `bias_hat` | 会不会整体偏高/偏低 |
| `var_hat` | 围绕趋势抖得厉害吗 |
| `mse_hat` | **直接用**能不能用 |

**为什么必须分开**：一个方案可以 MSE 很大但 bias 很小（纯方差问题），
也可以 bias 很大但 var 很小（**可用一个常数修正掉**）。
只看 MSE 会把两类完全不同的问题混为一谈，导致"该修哪个"无从判断。

**★ 关键设计：标定后的误差**

`mse_calibrated` 允许用真值做一次**仿射标定**（`a + b·S`）后的残差 MSE。
作用是把"**结构误差**"与"**尺度/偏移误差**"分开：
若远小于 `mse_raw` ⇒ 误差主要是尺度问题；若接近 ⇒ 误差是结构性的。

> **这是本项目最关键的一个设计**：正是它揭示了
> **"单一精度数字会把结论的符号搞反"**（见 `../05-验证/实验与验证报告.md` §3）。

**★ 关键设计：判定不预设方向（红线 G-3）**

`fusion_ledger` 的 `verdict` 取 `fusion_helps` / `fusion_hurts` / `inconclusive` 三值，
由数据决定。`tests` D19 专门断言"**融合更差时必须如实报 `fusion_hurts`**"。

**★ 关键设计：权重曲线必含 `rel_sd = 0`**

若 `rel_sd = 0` 时保留率**不是** 1.0，说明实现有问题。
**"恒不通过"和"恒通过"都是可疑信号**（来自 F1 方向 R-13 教训）。

### 3.5 `audit/audit.py` — 把缺失变成后果（Q3）

**职责**：把三条**报告缺失计数**各自映射到一个**可计算后果**。

| 函数 | 作用 | 输出 |
|---|---|---|
| `reclass_choice_sensitivity` | 重分类方案互换的后果 | ρ + 前 k 重叠 |
| `timeliness_flags` | 时效性检查清单 | **不含任何数字**（纪律 8） |
| `audit_summary` | 汇总 + 退化自检 | 三类后果在一张表 |

**★ 关键设计：本模块"不做什么"**

- **不重新统计**那些缺失计数（那是 Silverthorn et al. 2025 已完成的工作）
- **不接收任何真实研究的内部参数** ⇒ 只在**我们自己的合成场**上运行

**★ 关键设计：`timeliness_flags` 刻意不产数**

因为**我们不知道**任何具体研究的数据采集年份。
按纪律 8「无数据不产数」，它只返回"应当检查哪些项"的清单。
⇒ 这是**刻意设计，不是未完成**（`tests` E8 断言清单项不含数字）。

**★ 关键设计：`audit_summary` 内置退化自检**

它检查"传入的 `rel_sds` 是否含 0 且保留率恰为 1"，
并在缺失基线时报 `degeneracy_check.ok = False`。
`tests` E13 断言"**缺基线时必须报 False**" —— 这是一个**恒不通过自检**。

## 4. 数据流

### 4.1 单元实验数据流

```
make_multiscale_field(seed=0)
        │
        ├─ truth  ─────────────────────┐
        └─ layers ─→ minmax_normalize ─┤
                                       ▼
make_pond_layout ─→ mask ─→  wlc_score(Σw=1)  ─→ score
                              │
                              ├─→ scale_mismatch_curve(truth, mask)      [Q2]
                              ├─→ fusion_ledger({schemes}, truth, mask)  [Q1]
                              └─→ audit_summary(stack, w, mask, lo, hi)  [Q3]
```

### 4.2 三条纪律在数据流上的体现

| 纪律 | 体现 |
|---|---|
| **全部数据合成** | 入口唯一：`make_multiscale_field`。无任何外部数据读取 |
| **随机性完全由种子控制** | 所有 `default_rng(seed)` 显式传参；`tests` F5 断言同种子逐位可复现 |
| **不得外推真实塘口** | 效应量的输出文件名与 JSON 字段均带 `results_`/`note` 说明数据模式 |

## 5. 错误处理策略

**核心原则：退化输入必须报错，不得静默产出"看起来正常"的结果。**

| 情形 | 处置 | 理由 |
|---|---|---|
| 常数层进 min-max | `minmax_normalize` 静默产全 0，但 `assert_not_degenerate` **报错**；`audit_summary` 内置检查 | 全 0 层在 WLC 里等价于"该层无贡献"，**不报错**，属于静默失效 |
| WLC 权重未归一化 | **报错**，不静默缩放 | 否则量纲随权重漂移，精度与权重纠缠 |
| 权重含负值 / NaN | **报错** | 负权重使 WLC 失去补偿性语义 |
| 真值方差为 0 | **报错** | 保留率无定义，不是"0" |
| 池体像元 < 2 | **报错** | 无法排名 |
| 不能整除的 factor | **记入 `skipped_factors`**，不静默丢弃 | 否则"看起来全跑了" |
| 输入含 NaN | **报错**，不静默跳过 | 静默跳过会改变有效样本量而不留痕 |
| 无有效像元的粗格 | 返回 `NaN`，**不填 0** | 填 0 把"无数据"当"最不适宜" |

> 一致性：`tests` 中共 34 条 `expect_raises` 断言，覆盖上表每一行。

## 7. 已知限制

1. **无实测数据**：全部为合成场，效应量只能报**方向与相对量级**，不得外推。
2. **块平均只支持整数倍**：可测尺度是**离散的**（25/50/100/200/400 m）。
3. **不做统计推断**：无空间自相关校正（Moran's I 等），只做误差分解。
4. **权重与阈值均为示范性设定**：`rel_sd` 与 `lo/hi` 不代表实测值（红线 G-5）。
5. **未做全参数扫描**：只测了 `rel_sd` 与 `lo/hi` 两个旋钮。
