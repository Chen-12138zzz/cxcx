## 1. `src.synth` — 合成数据层

### 1.1 `make_multiscale_field`

```python
make_multiscale_field(
    n: int = 128,
    length_m: float = 3200.0,
    scales: tuple[float, ...] = (800.0, 200.0, 50.0),
    weights: tuple[float, ...] = (1.0, 0.6, 0.35),
    seed: int = 0,
    standardize: bool = True,
) -> dict
```

**返回字段**

| 字段 | 类型 | 说明 |
|---|---|---|
| `truth` | `ndarray (n,n)` | 真值场（若 `standardize=True` 则已标准化到 mean 0 / std 1） |
| `raw` | `ndarray (n,n)` | 标准化**前**的原始场 |
| `sd` | `float` | **标准化前的标准差（必须保留）** |
| `mean_raw` | `float` | 原始场均值 |
| `layers` | `dict[str, ndarray]` | 各结构层单独场，键名形如 `"L1_800m"` |
| `cell_m` | `float` | 网格间距（= `length_m / n`） |
| `length_m` | `float` | 场域边长 |
| `n` | `int` | 网格边长 |
| `scales` / `weights` | `tuple[float,...]` | 回显输入 |
| `seed` | `int` | 回显种子 |

**契约**：
- `len(scales) == len(weights)`，否则 `ValueError`
- **恒等式**：`truth * sd + mean_raw == raw`（`tests` A5 实测 `max|err| = 4.441e-16`）
- 同 `seed` ⇒ 逐位相同结果（`tests` A9）

**⚠️ 为什么 `sd` 是必留字段**：见 `02-核心算法设计说明.md` §1.3。

### 1.2 `make_pond_layout`

```python
make_pond_layout(
    n: int = 128,
    length_m: float = 3200.0,
    pond_side_m: float = 50.0,
    gap_m: float = 10.0,
    seed: int = 0,
) -> dict
```

**返回字段**：`pond_id`（`(n,n) int`，**−1 = 塘埂/道路**，≥0 = 池编号）、
`n_ponds`、`pond_side_m`、`gap_m`、`cell_m`、`length_m`、`n`、
`pond_area_ha`、`n_per_axis`。

**契约**：
- `pond_side_m + gap_m > length_m` ⇒ `ValueError`
- `pond_side_m < cell_m` ⇒ `ValueError`
- 池编号从 **0** 开始连续

**⚠️ 单池边长的依据**：3–5 亩 ≈ 0.2–0.33 ha ⇒ 方形边长 ≈ 45–57 m，
取中值 50 m。标 **【引用】+【待核实】**（`../00-项目管理/项目总览-README.md` §8 V-3）。

### 1.3 `block_average`

```python
block_average(field: np.ndarray, factor: int) -> np.ndarray
```

**契约**：
- 要求**方阵**，否则 `ValueError`
- `factor >= 1`，否则 `ValueError`
- `n % factor == 0`，否则 `ValueError`
- **保均值**（`tests` A12 实测 2047.5 == 2047.5）
- **刻意不提供**抽点采样路径（见 `02-核心算法设计说明.md` §2.1）

### 1.4 `target_factor_for_cell` / `effective_cell_m`

```python
target_factor_for_cell(cell_m: float, target_m: float) -> int
effective_cell_m(cell_m: float, factor: int) -> float
```

**契约**：`target_m <= cell_m` ⇒ 返回 `1`；
否则 `round(target_m / cell_m)`。
`effective_cell_m(cell_m, factor) == cell_m * factor`。

> ⚠️ **注意返回的 factor 可能无法整除 `n`**。调用方须自行检查（见 §6 陷阱 T-2）。

## 2. `src.mce` — 评价引擎

### 2.1 `minmax_normalize`

```python
minmax_normalize(x: np.ndarray, invert: bool = False) -> np.ndarray
```

**契约**：
- 输出恒在 `[0, 1]`（`tests` B1）
- `invert=True` 时顺序反转（`tests` B2）
- **⚠️ 常数层（极差为 0）静默返回全 0** —— 这是**刻意**设计，配套
  `assert_not_degenerate` 负责报错（`tests` B3 断言该退化行为已被文档化）

### 2.2 `assert_not_degenerate`

```python
assert_not_degenerate(x: np.ndarray, name: str = "layer", tol: float = 1e-12) -> None
```

**契约**：`max(x) - min(x) <= tol` ⇒ `ValueError`；否则**静默返回 `None`**。
返回值有意为 `None`（不是 bool）—— 强制调用方不可忽略其效果（`tests` B4、B5）。

### 2.3 `reclass_fuzzy`

```python
reclass_fuzzy(x: np.ndarray, lo: float, hi: float, edge: str = "both") -> np.ndarray
```

**契约**：
- `hi <= lo` ⇒ `ValueError`
- `edge ∈ {"both", "low", "high"}`，否则 `ValueError`
- 输出 clip 到 `[0, 1]`（`tests` B6、B7）
- `lo/hi` 是**物理解释边界**，不是数据极值 —— **必须由调用方给出**
  （本项目不自行编造领域阈值，红线 G-5）

### 2.4 `wlc_score`

```python
wlc_score(layer_stack: list[np.ndarray] | np.ndarray,
          weights: list[float] | np.ndarray) -> dict
```

**返回字段**：`score`（`(H,W)`）、`weights`（实际使用的归一化权重副本）、`K`（层数）。

**契约**（**全部报错，不静默处理**）：

| 输入 | 行为 |
|---|---|
| `layer_stack.ndim != 3` | `ValueError` |
| `len(weights) != K` | `ValueError` |
| 权重含非有限值 | `ValueError` |
| 权重含负值 | `ValueError` |
| `\|Σw − 1\| > 1e-9` | **`ValueError`**（不静默缩放） |

**线性性**：`score = tensordot(w, stack, axes=(0,0))`。
故对层序**不变**（`tests`/exp2 G7 实测 `max|diff| = 2.220e-16`）。

### 2.5 `normalized_weights`

```python
normalized_weights(raw: list[float] | np.ndarray) -> np.ndarray
```

**契约**：权重须有限非负，否则 `ValueError`；全 0 ⇒ `ValueError`；
返回值和为 1（`tests` B17、B18）。

### 2.6 `ahp_priority_from_consistent`

```python
ahp_priority_from_consistent(priority: list[float] | np.ndarray) -> dict
```

**返回字段**：`matrix`（`(K,K)` 判断矩阵）、`weights`、`consistency_ratio`、`lambda_max`。

**契约**：
- 优先级须**严格为正**，否则 `ValueError`
- `matrix` **互反**（`A_ij · A_ji = 1`）且**对角线为 1**，
  但**一般不对称**（`tests` B21 实测互反误差 0；B21b 实测 `max|A−Aᵀ| = 2.10`）
- 完全一致 ⇒ `consistency_ratio == 0`（`tests` B20）
- 回算权重能**复原**输入优先级（`tests` B19）

> **⚠️ I-2 修正记录**：该函数的返回注解原写作 `-> np.ndarray`，
> 但实际返回 `dict`。已修正。此类注解与实现不符的问题**不会被任何测试捕获**，
> 只能靠接口抽取核对 —— 见 §7。

### 2.7 `rank_descending` / `spearman_rho` / `top_k_overlap`

```python
rank_descending(score: np.ndarray, mask: np.ndarray | None = None) -> np.ndarray
spearman_rho(a: np.ndarray, b: np.ndarray) -> float
top_k_overlap(score_a: np.ndarray, score_b: np.ndarray,
              mask: np.ndarray | None = None, k: int | None = None) -> float
```

**契约**：

| 函数 | 契约 |
|---|---|
| `rank_descending` | 返回**索引**序列（非值）；`mask=None` 时用全部像元；并列用 `stable` 排序 |
| `spearman_rho` | 恒在 `[−1, 1]`；`a.size != b.size` ⇒ `ValueError`；`size < 2` ⇒ `ValueError`；至少一方为常数时返回 `1.0`（定义为完全一致） |
| `top_k_overlap` | `k` 缺省 `max(1, round(n × 0.10))`；参与像元数为 0 ⇒ `ValueError`；`k` 超过 `n` 时自动截到 `n` |

**⚠️ `_rankdata` 是内部函数**（不在 `__all__`），但其**行为正确性**被 `tests` B27
直接断言（平均秩 `[10,20,20,30] → [1, 2.5, 2.5, 4]`）。
⇒ 接口文档在此**显式标注"内部但已断言"**，以免后人误认为是无关实现。

## 3. `src.fusion` — 尺度与账本

### 3.1 `aggregate_to_coarse`

```python
aggregate_to_coarse(field: np.ndarray, factor: int,
                    mask: np.ndarray | None = None,
                    mode: str = "all_mean") -> np.ndarray
```

**契约**：

| 条件 | 行为 |
|---|---|
| `mode ∉ {"all_mean","pond_mean"}` | `ValueError` |
| 非方阵 | `ValueError` |
| `n % factor != 0` | `ValueError` |
| `mode="pond_mean"` 且 `mask is None` | **`ValueError`** |
| `mode="pond_mean"` 且某粗格内**无有效像元** | **返回 `NaN`（不填 0）** |

> **为什么 `NaN` 而不是 0**：填 0 会让下游把"无数据"当"最不适宜"
> —— 一个静默且**方向性**的错误（`tests` C2–C4）。

### 3.2 `scale_mismatch_curve`

```python
scale_mismatch_curve(truth: np.ndarray, mask: np.ndarray, cell_m: float,
                     factors: tuple[int, ...] = (1, 2, 4, 8, 16),
                     mode: str = "pond_mean",
                     k_frac: float = 0.10) -> list[dict]
```

**返回**：`list[dict]`，每个 dict 的字段：

| 字段 | 说明 |
|---|---|
| `factor` | 粗化倍数；**为 `None` 的项是"跳过记录"，不是数据行** |
| `coarse_cell_m` | 粗化后网格间距（米） |
| `grid_vs_pond_ratio` | 网格 / 单池（`coarse_cell_m / 50.0`） |
| `variance_retention` | **信息量**保留率 |
| `rank_agreement_cells` | 粗格间**决策**一致性（基准 `pond_mean`，得分 `all_mean`） |
| `rank_agreement_pooled` | 像元级ρ（粗格展开回像元） |
| `topk_overlap_pooled` | 像元级前 k% 重叠率 |
| `n_valid_cells` | 有效粗格数 |
| `n_pooled_pixels` | 展开后的有效像元数 |
| `mean_pond_fraction_in_cell` | 粗格内池体像元平均占比 |
| `note` / `skipped_factors` | **仅跳过记录项**有这两个字段 |

**⚠️ 消费接口时的必知事项**：

1. **必须过滤 `factor is None`** 的项，否则会把跳过记录当数据行：
   ```python
   rows = [r for r in curve if r.get("factor") is not None]
   ```
2. 不整除的 `factor` **不静默丢弃**，而是写入 `skipped_factors`。

**契约**：
- `mask.shape != truth.shape` ⇒ `ValueError`
- `var(truth[mask]) == 0` ⇒ `ValueError`（**分母取池体像元**，见 `修正记录.md` A-2）
- `mask.sum() < 2` ⇒ `ValueError`
- `factor < 1` ⇒ `ValueError`
- `factor=1` ⇒ `variance_retention` **恰为 1.0**（`tests` C9）

### 3.3 `pond_vs_grid_geometry`

```python
pond_vs_grid_geometry(n: int, length_m: float, pond_side_m: float,
                      gap_m: float, factors: tuple[int, ...]) -> list[dict]
```

**返回字段**：`factor`、`grid_m`、`cells_per_pond`（= `pond_side_m / grid_m`）、
`ponds_per_cell`（= `(grid_m / (pond_side_m + gap_m))²`）、
`grid_coarser_than_pond`（= `grid_m > pond_side_m`）、`ratio_grid_to_pond`。

> **⚠️ 语义澄清**：`cells_per_pond` 的字面含义是"**每口池占多少个网格**"，
> 但在网格粗于池时它会**小于 1**（如 1000 m 网格 → 0.05）。
> 此时更有意义的量是 `ponds_per_cell`（每格覆盖几口池）。
> **两个都要报**，否则读者会误读。
> （此处曾因语义混淆写错测试期望，见 `修正记录.md` B-4。）

**这是最稳的一组量** —— 纯几何，**不依赖任何数据**，无随机性。

### 3.4 `scale_mismatch_curve_perturbed`

```python
scale_mismatch_curve_perturbed(truth, mask, cell_m, factors=(1,2,4,8,16),
                               mode="pond_mean", seed=0, k_frac=0.10) -> list[dict]
```

### 3.5 `error_decomposition`

```python
error_decomposition(pred: np.ndarray, truth: np.ndarray,
                    mask: np.ndarray | None = None) -> dict
```

**返回字段**

| 字段 | 说明 |
|---|---|
| `n` | 有效样本数 |
| `mse_raw` / `rmse_raw` | 未经标定的误差 |
| `var_raw` | `pred` 的方差 |
| `bias_mean_raw` | `mean(pred − truth)` |
| `mse_calibrated` / `rmse_calibrated` | 仿射标定后（`a + b·pred`）的误差 |
| `var_resid_calibrated` | 标定后残差方差 |
| `calib_a` / `calib_b` | 标定系数 |
| `pearson_r` | 相关系数（**判别力**口径） |
| `var_truth` | 真值方差 |
| `nmse_raw` / `nmse_calibrated` | 以 `var_truth` 为标尺的归一化 |
| `share_of_error_from_scale` | `1 − mse_calibrated / mse_raw` |

**契约**：
- `pred.shape != truth.shape` ⇒ `ValueError`
- 有效样本 `< 3` ⇒ `ValueError`
- `var(truth) == 0` ⇒ `ValueError`
- **含非有限值 ⇒ `ValueError`**（不静默跳过；静默跳过会改变有效样本量而不留痕）
- **恒等式** `mse_raw == bias² + var`（exp2 G1 实测 `max|diff| = 2.220e-16`）

**两个必须记住的标定值**：

| 情形 | `share_of_error_from_scale` |
|---|---|
| `pred = 2·truth`（纯缩放） | **1.000000**（标定后 MSE 归 0） |
| `pred ⟂ truth`（纯随机） | **≈ 0.5**（**0.5 是"救不了"的上界，不是 0**） |

> ⚠️ 把纯随机情形的期望误写成"接近 0"会写出错误判据（`修正记录.md` C-3）。
> 实测 60 个种子 `mean = 0.5001, sd = 0.0104`。

### 3.6 `fusion_ledger`

```python
fusion_ledger(source_scores: dict[str, np.ndarray], truth: np.ndarray,
              mask: np.ndarray, baseline: str | None = None) -> dict
```

**返回字段**：`baseline`、`per_scheme`（逐方案 `error_decomposition`）、
`gain_vs_baseline`、`verdict`、`verdict_detail`。

**契约**：

| 条件 | 行为 |
|---|---|
| `source_scores` 为空 | `ValueError` |
| `baseline` 不在方案中 | `ValueError` |
| 任一方案形状与真值不符 | `ValueError` |
| `baseline=None` | 取**键名排序后的第一个**，并在 `baseline` 字段**显式报出** |

**增益正负约定**：`nmse_reduction > 0` 表示**优于**基线。

**判定规则（红线 G-3，不预设方向）**：

```
只看键名以 'fused' 开头的方案：
  全部 nmse_reduction > 0 → "fusion_helps"
  全部 < 0                → "fusion_hurts"
  符号混杂                → "inconclusive"
  无 'fused' 前缀方案      → "inconclusive"（不臆断）
```

> **⚠️ `verdict` 键在 `nmse_raw` 上**。这是一个**已知的设计取舍**：
> 它保证了"不预设方向"，但会因为 §4.3 的符号反转现象而给出
> 与判别力相反的判定。**消费方必须同时读 `pearson_r` 与 `nmse_calibrated`。**

### 3.7 `weight_perturbation`

```python
weight_perturbation(scores_by_layer, base_weights, mask,
                    n_draws: int = 200, rel_sd: float = 0.25,
                    seed: int = 0, k_frac: float = 0.10) -> dict
```

**返回字段**：`n_draws`、`rel_sd`、`k`、`n_units_ranked`、`base_weights`、
`spearman_vs_base`、`topk_changed_count`、`topk_kept_count`、`topk_kept_share`、`note`。

**统计子结构**（每个 `*_count` / `*_share` / `spearman_*` 字段）：
`{mean, median, p05, p95, min, max}`。

**契约**：
- `scores_by_layer.ndim != 3` ⇒ `ValueError`
- `len(base_weights) != K` ⇒ `ValueError`
- `\|Σ base_weights − 1\| > 1e-9` ⇒ `ValueError`

**★ 三个字段的语义（必须分清）**：

| 字段 | 含义 | `rel_sd = 0` 时 |
|---|---|---|
| `topk_kept_share` | 前 k% **保持率** | 1.0 |
| `topk_kept_count` | 前 k 名里**留住**的个数 | k |
| `topk_changed_count` | 前 k 名里**换掉**的个数 | **0** |

**恒等式**：`topk_kept_count + topk_changed_count == k`（逐次成立）。

> **⚠️ 语义歧义修正（见 `../05-验证/修正记录.md` **A-3**）**：
> `topk_kept_count` 曾**只有**"保留个数"这一个字段，
> 而字段名易被读成"换掉个数"，在 `rel_sd=0` 时会给出完全相反的心理预期
> （一个是 k，一个是 0）。现已补出 `topk_changed_count` 消除歧义。
> 这是**接口语义**层面的问题，不是计算错误 —— 代码一直是对的，错的是"读法"。

### 3.8 `weight_perturbation_curve`

```python
weight_perturbation_curve(scores_by_layer, base_weights, mask,
                          rel_sds=(0.0, 0.05, 0.10, 0.20, 0.30),
                          n_draws: int = 200, seed: int = 0,
                          k_frac: float = 0.10) -> list[dict]
```

**每项字段**：`rel_sd`、`k`、`n_units_ranked`、`spearman_mean`、`spearman_p05`、
`topk_kept_mean`、`topk_changed_mean`、`topk_kept_share_mean`、`topk_kept_share_p05`。

**★ 契约：`rel_sds` 必须含 `0.0`**（虽然签名不强制，但这是**使用契约**）：

> 若 `rel_sd = 0` 时保留率不是 1.0，实现有问题；
> 若它**恒为 1**（任何 `rel_sd` 都是 1），扰动没生效。
> ⇒ **"恒不通过"和"恒通过"都是可疑信号**（F1 方向 R-13 教训）。
> `audit_summary` 会**自动**检查这一点并报 `degeneracy_check`。

## 4. `src.audit` — 审计模块

### 4.1 `reclass_choice_sensitivity`

```python
reclass_choice_sensitivity(layer_stack, weights, mask, lo: float, hi: float,
                           schemes: tuple[str, ...] = ("minmax", "fuzzy"),
                           k_frac: float = 0.10) -> dict
```

**返回字段**：`schemes`、`n_units_ranked`、`pairs`、`lo`、`hi`、`note`。

`pairs` 每项：`pair`（形如 `"minmax__vs__fuzzy"`）、`spearman`、`topk_overlap`、
`k`、`topk_changed_mean`。

**契约**：
- `layer_stack.ndim != 3` ⇒ `ValueError`
- `schemes` 含未知方案名 ⇒ `ValueError`
- **`layer_stack` 是「原始物理量层」（未重分类）**，函数内部负责重分类

### 4.2 `timeliness_flags`

```python
timeliness_flags(consider_typo: bool = False) -> list[dict]
```

**返回**：每项含 `item`、`why`、`source_of_concern`。**不含任何数字。**

**★ 契约：本函数刻意不产数。**
因为我们不知道任何具体研究的数据采集年份。按纪律 8「无数据不产数」，
它只返回"应当检查哪些项"的清单。
⇒ 这是**刻意设计，不是未完成**（`tests` E8 断言清单项不含数字）。

### 4.3 `audit_summary`

```python
audit_summary(layer_stack, weights, mask, lo: float, hi: float,
              scale_curve: list[dict] | None = None,
              rel_sds=(0.0, 0.05, 0.10, 0.20, 0.30),
              n_draws: int = 200, seed: int = 0,
              k_frac: float = 0.10) -> dict
```

**返回字段**：`weight_sensitivity`、`reclass_sensitivity`、`scale_sensitivity`、
`degeneracy_check`（`{ok: bool, note: str}`）、`k_frac`。

**契约**：
- `\|Σ weights − 1\| > 1e-9` ⇒ `ValueError`
- `scale_curve` 是**参数传入**而非内部调用 —— 使 `audit` 与 `scale` 解耦
- **`degeneracy_check` 在缺 `rel_sd=0` 基线时必须报 `ok=False`**（`tests` E13）

## 6. 使用陷阱清单（踩过的坑）

| 编号 | 陷阱 | 正确做法 |
|---|---|---|
| **T-1** | 把 `src/` 本身加入 `sys.path` 后 `import fusion` ⇒ `ImportError: attempted relative import beyond top-level package` | 把 **`src` 的父目录**加入 path，然后 `from src.fusion import ...`（`修正记录.md` A-5） |
| **T-2** | `target_factor_for_cell` 返回的 factor **可能无法整除 `n`** | 用 `block_average`/`aggregate_to_coarse` 前自行检查 `n % factor == 0`；否则它们会报错 |
| **T-3** | `scale_mismatch_curve` 的返回里**混有跳过记录**（`factor is None`） | 一律按 `if r.get("factor") is not None` 过滤 |
| **T-4** | `minmax_normalize` 对常数层**静默**产全 0 | 先跑 `assert_not_degenerate`（`mce.py` 模块 docstring 已注明） |
| **T-5** | `cells_per_pond` 在网格粗于池时**小于 1**，易被误读 | 同时读 `ponds_per_cell` |
| **T-6** | 把 `share_of_error_from_scale` 的纯随机情形期望写成"≈0" | 正确渐近值是 **0.5** |
| **T-7** | `fusion_ledger` 的 `verdict` 键在 `nmse_raw` 上，可能给出与判别力相反的判定 | 必须同时读 `pearson_r` 与 `nmse_calibrated` |
| **T-8** | `ahp_priority_from_consistent` 的矩阵被当作"对称"使用 | 它是**互反**，不是对称 |

## 7. 接口一致性维护

### 7.1 为什么需要专门的检查

`consistency_check.py` 只做**文档之间**的校验。
**"代码签名 ↔ 接口文档"的一致性没有任何自动检查** ——
本次抽取就发现了 2 处问题（对应 `修正记录.md` 的 **A-6**、**A-7**），
它们**全部不会被任何测试捕获**：

| 编号 | 问题 | 是否会被测试捕获 |
|---|---|---|
| A-6 | `synth`/`mce` 缺 `__all__`（两个模块） | ❌ 不会（无测试依赖 `__all__`） |
| A-7 | `ahp_priority_from_consistent` 注解 `-> np.ndarray` 实返回 `dict` | ❌ 不会（注解不参与运行） |

⇒ 因此**每次改动 `src/` 后，应重跑接口抽取脚本并与本文核对**。
这两条也是本项目**唯一没有自动化断言守住**的缺陷类型，已如实登记。

### 7.2 抽取命令

```bash

# 输出各模块 __all__ 数量与逐函数签名；退出码 1 = 偏离基线
```

**当前基线**：`synth 5 / mce 9 / fusion 8 / audit 3 = 25`。
任何偏离都应视为**接口变更**，需同步更新本文并记录到 `../05-验证/修正记录.md`。

> ⚠️ **本脚本的能力边界**：它只能核对**符号数量与签名**，
> **不能**核对「返回注解与实现是否相符」（注解不参与运行，需运行期样本才能验证）。
> A-7 正是这一类 —— 因此**改动 `src/` 后必须同时人工复核返回注解**。

### 7.3 与测试的关系

`tests/run_tests.py` 直接 `from src.xxx import yyy`。
⇒ **任何被断言的符号若被改名或删除，测试会立刻失败**。
但**未被断言的符号**（如 `target_factor_for_cell` 之外的导出项）改动则不会被发现
⇒ 这是本接口文档存在的意义。
