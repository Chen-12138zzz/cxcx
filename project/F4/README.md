# F4 · 面向高位池小水体的多源地理空间融合适宜性评估与可复现性审计

> **一句话定位**：不发明新的选址方法，而是把「多源融合的成本—收益账」与「既有选址模型的可复现性」

## 1. 这个项目做什么

回答三个问题：

1. **融合换来了多少精度？代价是多大方差？** —— 把遥感、气象、海温、地形等多源数据融合进
   高位池尺度的适宜性评估，量化**融合的代价结构**，而不是预设"融合一定更好"。
2. **当输出网格粗于决策单元时，精度数字还能不能站得住？** —— 高位池单池 **3–5 亩 ≈ 0.2–0.33 ha**
   （池体约 50 m 量级），而主流 GIS-MCE 的输出栅格常为 30 m–1 km。
3. **已发表的 GIS-MCE 选址研究，结论有多可复现？** —— 把"未报告权重/分辨率"这类**缺失计数**，
   升级为**可计算后果**（权重扰动 → 排序翻转概率；分辨率变化 → 结论稳定性）。

**本项目明确不做**：不出具任何"某地块适合/不适合养殖"的结论，不产出选址图，不给管理建议。
理由见《00-项目管理/项目总览-README.md》§5.3 红线 G-1/G-2 —— 无现场真值，选址图不可证伪。

## 3. 三条硬纪律（读任何文档前请先接受）

1. **全部结论都不是真实地理结论。** 本项目**无高位池现场准入、无实测真值**。
   所有精度/误差数字来自**合成场**或**文献引用**，每处都标了数据模式。
   不存在"实测准确率"这一类数字。
2. **这**不是**"没人做过"型立项。** GIS-MCE 养殖选址是高度成熟的领域
   （见 `01-调研/03-参考文献清单.md`）。本项目的依据是**领域公认缺口**（2023 综述未讨论不确定性；
   2025 报告框架统计出 49/71 篇未报空间分辨率），不是"无人研究"（该表述属禁用词）。
3. **本项目不含任何选址建议。** 见 §1 末段与红线 G-1/G-2/G-6。
