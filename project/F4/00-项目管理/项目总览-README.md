## 2. 立项依据

### 2.1 一句话立论

> **本项目不发明新的选址方法，而是把「多源融合的成本—收益账」与「既有选址模型的可复现性」变成可计算、可审计的东西。**
>
> 它回答三个问题：
> **① 把遥感、气象、海温、地形等多源数据融合进高位池尺度的适宜性评估，融合到底换来了多少精度？代价是多大方差？**
> **② 当融合结果的输出网格粗于高位池本身（单池 3–5 亩 ≈ 0.2–0.33 ha）时，任何精度数字还能不能站得住？**
> **③ 已发表的 GIS-MCE 选址研究，其结论在多大程度上可复现、可被下游使用者判断适用范围？**

**本项目明确不做的事**：不出具任何「某块地适合/不适合养殖」的结论、不产出选址图、不给出管理建议。
理由见 5.3 红线 G-1/G-2 —— 无现场真值可验证，任何选址图都不可证伪。

### 2.2 依据的性质说明（三问，必须回答）

| 问 | 回答 |
|---|---|
| 这是**能力差异型**依据还是**空白型**依据？ | **能力差异型 + 方法缺口型。** 核心能力＝① 地理空间栅格数据的工程化融合与尺度诊断能力；② 把「审计协议」本身当作研究对象的方法工程能力 |
| **空白型依据占比**是多少？ | **0%。** 本项目的论证不建立于"无人做"。相反，本轮检索实测显示 GIS-MCE 是**高度成熟、大量产出的领域**（见 2.4），把"没人做适宜性评估"当依据会立刻被反例击穿 |
| 是否声明了「未见披露 ≠ 不存在」？ | **是**，见 5.1 与《01-竞品与近邻尽调》第 0 节 |

### 2.3 差异化落点

**本项目刻意选择的不是"方法新"，而是"审计对象新"。**

| 对比对象 | 它做的是 | 本项目做的是 |
|---|---|---|
| Chentouf et al. 2023（ISPRS IJGI 12(10) 439）| **盘点**：综述 31 篇，归纳出鱼类/贝类两套通用准则模型 | **量化**：对同一套 GIS-MCE 流程做**可计算的不确定性传播与尺度误差分解**，给出数字而非清单 |
| Silverthorn et al. 2025（PLOS Sustain. Transform. 4(1) e0000155）| **规范**：提出报告清单，指出 49/71 篇未报空间分辨率、13 篇未报权重 | **度量**：把"未报权重"从**缺失计数**升级为**推断方差的可计算后果**（权重扰动 → 排序翻转概率） |
| 主流 GIS-MCE 选址研究（Kumar 2023 / Mardani 2025 等）| 面向**海湾、河口、大范围海域**的宏观选址，栅格常为 30 m–1 km | 面向**高位池级小水体**（单池 0.2–0.33 ha），研究**输出网格粗于决策单元**时的尺度失配 |
| E8（无人机与遥感工程应用）| 遥感**工程应用**：怎么把无人机飞起来、把数据取回来 | 遥感数据的**融合方法的代价结构**：融合换来的精度 vs 引入的方差与可复现性损失 |
| F11（卫星水质反演与地面校核）| 单一数据源的**反演精度**（已被组织级竞赛证伪，见 8 节 V-2） | 多源的**融合与传播过程**，不承诺反演精度 |
| F1（因果推断与干预效应）| 管**从数据能否推出因果结论** | 管**从多源数据能否推出空间决策**（不涉及干预与反事实） |
| F3（模型评测基准与公平性）| 管模型**性能**的跨群体公平性 | 管**空间决策结论**的可复现性与尺度适用性 |
| F14（可复现性审计）| 管养殖 AI 论文**能不能重跑出来** | 管空间选址结论**在尺度变化下是否还成立**（复现的对象是"方法链"而非"模型权重"） |

**关键差异一句话**：别人在**产出**适宜性图；本项目在**审计**产图这件事本身 ——
且审计对象是**本领域公认正在发生的问题**（2023 综述指出未讨论不确定性、2025 报告框架统计出 49/71 篇未报分辨率）。

**依据的三问自检**：

1. **空白型占比** = 0/8 = **0%**。S1–S8 全部是"已存在的问题尚未被转化为可计算方法"（方法缺口型），
   没有一条依赖"没人做过适宜性评估"。
2. **问 2 的答案是"动机不匹配"还是"粒度不匹配"？**
   → **粒度不匹配**。本研究区主流 GIS-MCE 的决策单元是**海湾/河口级**（栅格 30 m–1 km），
   而高位池的池体尺度是 **~50 m 量级、单池 0.2–0.33 ha**。做海湾选址的团队**动机上不需要**
   解决"输出网格粗于池体"的问题 —— 这构成真实的差异，不是"他们没想到"。
3. **是否声明「未见披露 ≠ 不存在」？** 是。见 5.1。

## 5. 表述红线（**本项目全文适用**）

### 5.1 三条否定性结论纪律

1. 禁用「均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 / 未检索到同类 /
   国内首个 / 首创」为**禁用词**；改用「**在所及范围内未见**」。
2. 否定性判断必须给出**举证范围与日期**，不得只写结论。
3. 「**未见披露 ≠ 不存在**」必须显式写出。

### 5.2 数据模式标注（强制）

每个数字/结论必须标注其模式：

| 标记 | 含义 |
|---|---|
| **【实测】** | 本项目自己跑出来的，可复现，原始数据在 `05-验证/` |
| **【合成】** | 由已知空间结构的合成数据产出，**不得表述为真实地理结论** |
| **【引用】** | 来自他人文献/官方发布，须给出来源 |
| **【待核实】** | 未独立核实的二手材料 |

> ⚠️ **本项目无「真值」这一档**。因为 U-1 决定了本项目拿不到高位池实测量，
> 所以**不存在"实测准确率"这类数字**。凡出现精度/误差数字，必须同时说明它来自合成场还是引用。

### 5.3 地理空间专属红线（**本方向特有，最容易踩**）

| # | 红线 | 为什么 |
|---|---|---|
| G-1 | **不得产出"某地块适合/不适合养殖"的结论，不得给出选址建议** | 无高位池真值可验证，选址图不可证伪；且下游可能据此投资 |
| G-2 | **不得把合成场/MCE 打分表述为真实地理适宜性** | 合成场的空间结构是研究者设定的假设，不是地理事实 |
| G-3 | **不得声称融合一定提升精度** | 融合也可能引入尺度失配与新的估计误差；本项目恰恰要**量化**这件事，而非预设方向 |
| G-4 | **不得把"高分辨率"与"高精度"混为一谈** | 数据空间分辨率提升不自动带来决策质量提升；两者必须分开测量 |
| G-5 | **任何依赖给定权重情景的结论必须声明"权重仅为示范性设定"** | AHP 权重主观性是被审计对象本身，不是我们的立场 |
| G-6 | **不得作行政/政策建议**（如"建议此处划为限养区"） | 超出能力范围，且涉及行政判断 |
| G-7 | **输出网格粗于决策单元时必须显式声明该失配** | 这是本项目最核心的观察之一，不得在结果里隐瞒 |

### 5.4 九条诚实性纪律

1. 数据模式标注（5.2）—— **每个数字都要标**。
2. 核验状态标注 —— `[已核验·原文通读]` / `[已核验·元数据]` / `[待核实]`。
3. 全称表述禁用（5.1）。
4. **未做的不得写成已做**。
5. **失败必须留痕** —— 被淘汰的方案、不理想的指标一并保留。
6. 局限清单必须显式列出（见 05-验证）。
7. 修正记录公开（第 6.2 节）。
8. **无数据不产数** —— 没有原始数据就不给结论、不填占位值。
9. 演示数据必须标明（合成数据不得伪装成真实地理数据；不得附带真实经纬度）。
