## 3. 统计口径（统一，不得各写各的）

### 3.1 中文字符计数（用于文档字数统计）

**唯一口径**：

```python
import re
n_cn = len(re.findall(r"[\u4e00-\u9fff]", text))
```

**说明**：
- 只计 **CJK 统一汉字基本区**（U+4E00–U+9FFF）。
- **不含**：标点（含中文标点如 `，。、；：`）、数字、拉丁字母、空白、
  扩展区汉字（U+3400–U+4DBF、U+20000+）、兼容区汉字（U+F900–U+FAFF）。
- 因此"总字符数"与"中文字数"是两个不同的量，**报告时必须写明用的是哪个**。

### 3.2 误差口径

| 量 | 公式 | 归一化标尺 |
|---|---|---|
| `mse_raw` | `mean((pred − truth)²)` | — |
| `nmse_raw` | `mse_raw / var(truth)` | `var(truth)` |
| `mse_calibrated` | 仿射标定 `a + b·pred` 后的残差 MSE | — |
| `share_of_error_from_scale` | `1 − mse_calibrated / mse_raw` | — |

**恒等式**：`mse_raw == bias² + var`（容差 1e-9）。

### 3.3 一致性口径

| 量 | 定义 | 分子/分母必须同总体 |
|---|---|---|
| `variance_retention` | `Var(粗格聚合值) / Var(truth[mask])` | ✅ **分母是池体像元**（不是全像元） |
| `rank_agreement_cells` | `ρ(粗格 all_mean, 粗格 pond_mean)` | ✅ 两个**不同构造** |
| `topk_overlap_pooled` | `|前k∩前k| / k`，`k = max(1, round(N·0.10))` | ✅ |
| Spearman ρ | 平均秩，无 scipy 依赖 | — |

### 3.4 样本量口径

| 场景 | 样本量 | 说明 |
|---|---|---|
| 尺度诊断（exp1） | **11236** 池体像元 | `mask.sum()` |
| 误差分解（exp2） | **11236** 池体像元 | 与上一致（同一 support 才可比较） |
| 权重扰动（exp3） | `k = 1124` | `max(1, round(11236 × 0.10))` |

> ⚠️ **不允许**在不同 support 之间比较精度（F1 方向 R-2 教训）。
