## 二、立项依据

### 2.1 一句话立论

> **本项目不发明新的选址方法，而是把「多源融合的成本—收益账」与
> 「既有选址模型的可复现性」变成可计算、可审计的东西。**

### 2.2 三个待回答的问题

| # | 问题 |
|---|---|
| ① | 把遥感、气象、海温、地形等多源数据融合进高位池尺度的适宜性评估，**融合到底换来了多少精度？代价是多大方差？** |
| ② | 当融合结果的输出网格**粗于高位池本身**（单池 3–5 亩 ≈ 0.2–0.33 ha）时，任何精度数字还能不能站得住？ |
| ③ | 已发表的 GIS-MCE 选址研究，其结论在多大程度上**可复现、可被下游使用者判断适用范围**？ |

## 三、研究内容与技术路线

### 3.1 三个研究内容（对应三个问题）

| 内容 | 方法 | 产出 |
|---|---|---|
| **A. 融合的代价结构** | WLC 误差三分解（bias / variance / MSE）+ 仿射标定分离结构误差与尺度误差 | 融合账本：逐方案误差 + 相对基线增益 |
| **B. 尺度失配诊断** | 块平均粗化 + 三个分离量（信息量保留率 / 粗格决策一致性 / 像元级决策一致性）+ 前 k% 重叠率 | 尺度失配曲线 + 纯几何诊断 |
| **C. 可复现性审计** | 把三条报告缺失计数各自映射到可计算后果（权重扰动 → 排序翻转；重分类互换 → 方案置换；分辨率 → 尺度代价） | 缺失→后果映射表 |

### 3.2 技术路线

```
合成真值场（三层可分辨：800 / 200 / 50 m）
        │
        ├─→ 多源"数据"层 ─→ 重分类（min-max / fuzzy）─→ WLC 融合 ─→ 得分场
        │                                                          │
        │              ┌───────────────────────────────────────────┤
        │              ▼                       ▼                   ▼
        │        尺度失配诊断            融合账本              审计模块
        │        (内容 B)                (内容 A)              (内容 C)
        │              │                       │                   │
        └──────────────┴───────────────────────┴───────────────────┘
                              真值已知 ⇒ 全部误差可精确计算
```

### 3.3 关键设计决策

| 决策 | 理由 |
|---|---|
| **用合成场而非真实遥感影像作为主实验** | 本项目**唯一**能拿到真值的途径（U-1 无现场数据）。主结果建立在**已知真值的合成场**上，故"方法正确性验证"本身即是成果（应对 R-3） |
| **自实现 WLC/AHP 而非调用 GIS 库** | 需要在"权重变化 0.01 时排序变了几个"这一粒度上测量；现成库把步骤封装为不可分解的黑箱 |
| **误差必须三分解** | 一个方案可以 MSE 很大但 bias 很小（纯方差问题），也可以 bias 很大但 var 很小（**可用一个常数修正掉**）。只看 MSE 会把两类完全不同的问题混为一谈 |
| **信息量与决策一致度分开报** | 一个方案可以"保留 94% 的方差"却"把前 10 名换了 22%" |
| **不预设融合方向** | 红线 G-3；`fusion_hurts` 分支保留且已通过测试 |
