## 0. 阅读须知：本文件能证明什么、不能证明什么

**能证明的**：在 2026-09-20 这一天，以「AI 输出可信性 / 预警问责」为关键词做人工与检索式尽调，
在所及范围内找到下列竞品，且它们的公开材料均未披露「事实与问责层」的输出可信机制。

**不能证明的（必须显式声明，这是本文件成立的前提）**：
1. 「未见披露」≠「他们没有做」。厂商只宣传做到了什么，不主动披露自己没做什么。
   本文件所有「未见披露」均应读作 **「在所及范围内未见披露」**，不得读作「不存在」。
2. 本文件未做付费数据库检索（企查查/知产宝/万方深检），未做展会与内网资料检索。
3. 【子代理】标记的条目为二手材料，未回溯一手来源，采信级别低于【已核实】。
4. 本文件不含任何排他性主张（「本项目是第一个」「××方向没有人在做」这类判断）。
   该类判断在本项目中**禁用**，理由见第 5 节。

## 1. 尽调方法：为什么是这个顺序

上一轮项目《蓝哨》的复盘给出了明确教训：**先尽调，后建造；且尽调必须从最近的人开始。**

因此本次尽调按固定的五级半径由近及远执行，**每一级都必须留下检索记录**，
不允许跳级（跳级会导致「查了全国公司、漏了隔壁实验室」这种最致命的失败）：

| 级别 | 半径 | 本方向的实际结果 |
|---|---|---|
| L1 | **同校**（广东海洋大学） | 命中，见第 2.1 节 |
| L2 | **同城学生团队**（湛江） | 命中，见第 2.2 节 |
| L3 | **同城公司/机构**（湛江） | 命中，见第 2.3 节 |
| L4 | **国内公司/高校** | 命中，见第 2.4、2.5 节 |
| L5 | **国外/通用工具与学术文献** | 命中，见第 2.6、2.7 节 |

**顺序的强制含义**：本文件完成之前不得启动第 2 阶段（写唯一事实来源）。
因为如果 L1/L2 已经成套占位，那么任何后续立论都是无效劳动。

| 但它带来两个现实约束 | ①**资源约束（有利）**：同学院已有算力与实验条件，本项目的边缘/低算力实验可申请使用；②**差异化约束（不利）**：校内已有强队在做智慧渔业，本项目若做成"又一视觉/感知系统"，在校内评审环节即被同门比下去 |

### 2.2 L2 · 同城学生团队：湛江科技学院「智擎虾塘」（**最强近邻，风险最高**）

| 项 | 内容 |
|---|---|
| 单位 | 湛江科技学院学生团队（同城、同为本科生队伍） |
| 时间 | 2026-05 报道 |
| 落地情况 | 遂溪 / 坡头 **7 家养殖户试点** |
| 技术内容 | 水下监测浮标（浑浊水体识别残饵）+ 残饵识别双模型投喂决策 + **投饵机低成本智能化改造** |
| 效果表述 | 投喂误差 < 5%、饲料浪费降低 15%+（引自其公开报道，本项目未独立复现） |
| 知识产权 | 已有发明专利与软件著作权 |
| 核实状态 | 【已核实】 |

> **为什么这是全表最危险的一条**：它证明「同城学生团队能做到"算法 + 硬件 + 真实塘口试点"」。
> 任何以"学生队做不了现场"为由的方案，都会被这一条直接顶回来。
> **它不占位 E10**（其材料全部指向投喂执行链，未见任何输出可信性/问责机制），
> 但它把本项目的"可实现性"门槛抬高了：**我们做不了硬件与塘口，就绝不能声称在做硬件与塘口。**

|---|---|---|

| 湛江湾实验室「海洋渔业可信数据空间」（2025-09 报道） | 金鲳鱼孵化到上市区块链「数字身份证」；苗种/水质/投喂/检测全程可溯 | 注意：它的"可信"指**数据上链可信（防篡改）**，不是**模型输出可信**。两者的区别必须在本项目中说清楚，否则会被评审误认为重复 |

> **E10 机会点**：以上三者的共同特征是**「给裸建议」**——给出结论，但不给依据、不给置信度、不给失效条件。
> 这正是 E10 「事实与问责层」的切入点。

**意义（对本项目是双重约束）**：
1. **合规门槛被抬高**：一个已备案的商用产品在同一个语义域内。本项目**不得**声称自己在做"养殖问答/诊断"，
   否则直接撞车。
2. **它也在"给裸建议"**：其公开材料未见披露逐数字溯源、置信度标注、拒答回退。
   这与 2.3 三条湛江占位者构成同一类缺口——**这是本项目立论的实证基础**。

### 2.7 L5 · 学术文献层

本方向检索到 **17 篇**候选文献（检索式 5 条，见 `03-参考文献清单.md`）。
统计口径与两批检索的差异见 `03-参考文献清单.md` 第 1 节，此处只给结论性判断：

- 检索到的文献集中在**通用 MLOps / 漂移监测 / 幻觉检测 / 不确定性量化**，
  落点是**方法**，不是**养殖场景下的问责**。
- 因此文献层同样**不构成空白**：通用方法早已成熟。本项目的价值不在方法首创，
  而在**把一个成熟方法绑到一个真实有人看、错了有人赔的输出场景上**。

## 4. 由尽调直接得出的三条硬约束（进入《能力与约束》表）

1. **不得做硬件、不得声称有塘口**。同城学生队已在 7 家养殖户试点，
   任何越界声称都会被"湛江科技学院已经做了"一句击穿。
2. **不得做通用可信性工具**。开源 Ragas/Evidently 与商用 MLOps 平台已成熟，
   "做一个漂移检测器"在本方向无立项价值。
3. **不得撞"养殖问答/病害诊断"**。北冥智渔已备案，直接撞车即合规风险。
