## 4. 硬性写作纪律

1. **禁用表述**：均为 / 仅见 / 没有人 / 无人研究 / 完全空白 / 尚属空白 / 未检索到同类 /
   国内首个 / 首创 / 全国第一 / 我们第一个。改用「**在所及范围内未见**」。
2. **必须写明**：「未见披露 ≠ 不存在」——尤其在第 2.4 节引用稷安智算处。
3. **约束必须如实写**：无塘口、无水产成员、经费 1 万、无硬件。
   **不得**把约束包装成创新（例如不得写"因为无法获得现场数据，因此本项目创新性地采用仿真"）。
4. **必须保留弱项**：立论的四个脆弱点（见选题论证第 5 节）须在"风险与应对"中如实呈现。
5. **数据模式标注**：每个数字后标注【实测】/【合成】/【仿真】/【引用】/【自测·《蓝哨》】/【待核实】。
6. **不得虚构**：项目成员、学号、导师、经费数额一律用 `【待填：字段名】` 占位，不得编造。
7. **引用格式**：正文引用用 `[序号]`，序号对应 `03-参考文献清单.md` 第 3 节表格行号。
