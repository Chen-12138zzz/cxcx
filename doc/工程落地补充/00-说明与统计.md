# 工程落地补充 · 检索说明与统计

**检索日期**：2026-09-20　|　**数据源**：**Crossref REST API**（api.crossref.org）

> **为什么用 Crossref 而不是 OpenAlex**：本批检索开始时，OpenAlex 对本机出口 IP 触发了**持久 HTTP 429 限流**
> （单条请求亦 429），Semantic Scholar 同样 429；Crossref 可用，故本批以 Crossref 为数据源。
> **代价**：OpenAlex 直接提供机构 `country_code`，而 Crossref **只给机构名称字符串、无国别字段**，
> 因此本批的「国别」为**按机构名称推断**（见下），且部分记录完全没有机构信息。
> **因此：本批的「国内占比」口径弱于第一批，且是保守下限，详见第四节局限。**

## 四、局限

1. **中文期刊覆盖有限**：OpenAlex 对 CNKI / 万方收录不全，需中文核心期刊须另行检索 CNKI。
2. **落地标记为标题启发式**：仅作筛选线索，不作结论。
3. **未做引文追踪**：建议对每方向前 3 篇高被引综述补充引文追踪。
4. **年份以 OpenAlex 记录为准**：引用前以 DOI 原文为准。
5. **本清单只提供元数据**，不含论文结论与数字。
