> **本目录只有元数据，不含论文结论与数字** —— 引用具体结论必须阅读原文。

## ⚠️ 先读这一段：两批文献**口径不同，不可直接相比**

本目录下实际有**两批**检索结果，它们用了**不同的数据源**，因此「国内占比」这个指标
**在两者之间不可比**：

| 批次 | 位置 | 篇数 | 数据源 | 国别口径 |
|---|---|---|---|---|
| **第一批** | `doc/`（本层） | **133** | **OpenAlex** | 有机构 `country_code` 字段，**严格口径** |
| **第二批** | `doc/工程落地补充/` | **332** | **Crossref** | **无国别字段**，按机构名启发式推断，覆盖率 68.1% ⇒ 国内占比是**保守下限** |

**为什么第二批换了数据源**：检索当时 OpenAlex 对本机出口 IP 触发了**持久 HTTP 429 限流**
（单条请求亦 429），Semantic Scholar 同样 429，Crossref 可用。

**⇒ 引用「国内占比」时必须声明批次口径。** 两批合计 **475 篇**。

## 局限（两批共同）

1. **中文期刊覆盖不足** —— OpenAlex / Crossref 对 **CNKI / 万方** 收录不全。
   本目录的"国内文献"主要是中国学者发表于**国际**期刊 / 会议的英文论文。
   **要覆盖中文核心期刊须另行检索 CNKI —— 本工作区未做，且必须在申报材料中如实声明。**
2. **第二批的国别是推断值** —— Crossref 无国别字段，按机构名启发式判断，覆盖率仅 68.1%。
3. **未做引文追踪** —— 仅做主题检索。建议对每方向前 3 篇高被引综述补「参考文献回溯 + 被引追踪」。
4. **年份以数据源记录为准** —— 在线优先出版可能造成年份偏差，**引用前以 DOI 原文为准**。
5. **只提供元数据** —— 不含论文结论与数字。
